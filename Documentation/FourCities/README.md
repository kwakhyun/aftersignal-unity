# 네 도시와 문화 시설

요청 시작 시 기존 변경 전체를 `d1eacacd`로 커밋하고 `origin/main`에 푸시했다. 이번 확장의 소스는 그 이후 변경이다.

## 실행과 찾아가기

`PLAY.cmd`는 `Builds/active-player.txt`에 지정된 Windows 플레이어를 실행한다. 이번 빌드는 `Builds/FourCities/AFTERSIGNAL.exe`다. Unity 프로젝트를 열 때는 `Assets`, `Packages`, `ProjectSettings`가 들어 있는 저장소 폴더를 선택한다.

- **M**: 현재 위치 중심 지도. 도시 탭, 시설 검색, 스포츠/문화/숙박/교통/캠페인/생활 분류, 휠 확대, 드래그 이동, 목적지 지정, 내 위치 복귀.
- **E**: 안내 데스크·매표소·직원 대화·기록 단말·승강기. 승강기 앞에서 호출하고 객실 안에서 목적 층 선택.
- **J → 네 도시의 증언 · 시설 내부 캠페인**: 12장 연계 캠페인과 현재 목표 추적. 지정된 건물과 층의 기록 단말을 조사한다.
- **F**: 놀이기구에서 하차. **ESC/Space**: 캠페인 연출 건너뛰기.

## 지역과 시설

애프터라이트 북쪽 문화지구: 루멘 크라운 식물원, 세븐 시그널 전망탑, 던 유나이티드 축구장, 오로라 야구장, 펄스 농구 아레나, 에이펙스 스트리트 서킷, 프리즘 시네마.

노바 남쪽 관광지구: 노바 아크 그랜드호텔, 타이드 원더파크, 기억의 파도 박물관, 트라이던트 스타디움, 해협 문라이트 볼파크, 오비탈 실내체육관, 홀로웨이브 시네마, 해협 빛의 등대.

동쪽 에레보스: 격리 관문, 침묵한 방송국, 정지된 기억병원, 역중력 기록성당, 영점 공명로. 파손된 외벽·노출 골조·부유 잔해와 별도 안개/하늘을 사용한다. 관문 이후 잠식 시민과 기계적 다족 방어체가 공격한다. 일반 주거 인구는 배치하지 않는다.

노바 동쪽 해저 도로를 따라가는 네레이드: 감압 관문, 산호 정원, 해저 연구원, 시민 포럼, 생활시장, 종합의료원, 주거 호텔, 블루 아카이브. 돔과 기밀 터널 안은 걸을 수 있는 건조 공간이다. 밖의 바닷속에는 기존 수영·잠수·산소 시스템이 적용된다. 내부 도로는 일반 도로, 바다를 통과하는 구간은 밀폐 터널로 구분한다.

총 28개 주요 시설은 데이터 카탈로그와 실제 월드 위치, 메뉴, 지도, NPC 안내를 공유한다. 주변 혼합 용도 블록은 도로와 주요 시설을 피해서 생성하고 기존 고층 건물 진입 시스템을 연결한다. 경관은 직접 작성한 메시와 기존 재질을 조합한 게임용 절차적 모델이다. 상용 게임 수준의 수작업 자산이나 모든 시설의 완전한 경영 시뮬레이션으로 보아서는 안 된다.

## 운영과 경기

직원은 담당 데스크/업무실 근처에서 업무·순회를 하고, 방문객은 전시·휴식·관람 지점을 오간다. 관중은 좌석에 앉고 일부는 이동한다. 선수가 별도로 코트에 배치되며 경기 이벤트와 진영에 따라 이동·행동·공의 궤적이 갱신된다. NPC는 근거리에서 생성·활성화하여 동시 처리량을 제한한다.

| 종목 | 적용한 핵심 규칙 | 관전용 시간 |
|---|---|---|
| 축구 | 11 대 11, 전후반, 골, 오프사이드, 반칙, 페널티킥, 정규시간 무승부 | 경기 시계 18배 |
| 농구 | 5 대 5, 4쿼터, 2/3점·자유투, 24초, 리바운드, 팀 파울, 동점 연장 | 경기 시계 8배 |
| 야구 | 9명 수비, 볼/스트라이크, 3아웃, 주자 진루, 9회말 생략, 끝내기, 연장 승부치기 | 이닝 종료 방식 |
| 자동차 경주 | 2팀 6대, 8랩 완주 순위, 팀별 10/8/6/4/2/1점 합산 | 실시간 주행 |

타석이 끝날 때 타순을 넘기고 축구 하프타임/농구 후반에는 공격 방향을 바꾼다. 종목별 심판 규정 전체나 전문 스포츠 게임의 직접 조작·충돌 엔진을 재현한 것은 아니다. 규칙 상태가 진행과 결과를 결정하고 표현 계층이 이를 시각화한다. 매표소의 '오늘 경기'에서 현황을 갱신해 볼 수 있다. 경기 전 팀 승리에 100 C 예측, 적중 시 원금 포함 200 C, 무승부 원금 반환. 시작 후 접수 금지, 경기당 1건, 중복 정산 방지 및 저장/복원. 현실 화폐는 사용하지 않는다.

놀이공원: 대관람차 30 C, 궤도 코스터 40 C, 회전목마 15 C. 운전원·대기열·탑승/운행/하차 주기, 실제 움직이는 객실과 시민 탑승을 구현했다.

호텔: 120 C로 8시간 취침/체력 회복, 30 C 식사. 병원: 80 C 완전 회복. 수중 시장: 25 C 도시락, 35 C 에너지 충전. 영화관: 25 C로 직접 제작한 원본 60초 영상 `SIGNAL / 심해의 빛` 관람. 상영 정보 메뉴에 제작·이용 허가를 표시한다.

## 스토리와 표현

박물관의 누락 기록 → 심해 증언 → 격리 관문 → 방송국·병원·기록성당 내부 전투 → 해저 연구원 → 방송국 재송출 → 공명로 보스/결정 → 시민 포럼 → 복원 전시로 이어진다. 층 이동, 위협 제거, 기록성당의 세 코어 동기화, 지정 단말 조사를 진행 조건으로 사용하며 장별 보상과 진행 저장을 제공한다. 공명로에서 선택한 공개/보호 방침은 시민 포럼의 후속 대사에 반영된다.

연출은 외부 전경, 증언자 홀로그램, 서하 반응의 세 카메라 숏으로 구성한다. 카메라 이동·화각·페이드·레터박스·한글 자막·건너뛰기·조작 복원을 처리한다. 음성 배우 녹음이나 얼굴 모션 캡처 영상은 포함하지 않는다.

새 NPC 시트 8종: 축구·야구·농구 선수, 레이서, 심해 기술자·시민·의료인, 잠식 시민. 각 시트 16프레임, 앞/오른쪽/뒤/왼쪽 방향으로 기존 도트 계열에 맞춰 제작했다. 이미지 제작 프롬프트는 `ART-PROMPTS.json`, 건축·규칙 참고 및 원본 영상 출처는 `REFERENCES.md`.

## 필수 검증 기록

- `Artifacts/FourCities/rules.json`: 경기 종료, 연장전, 끝내기, 볼넷/주자, 오프사이드, 도로 연결과 호흡 범위 등 25개 규칙 검사.
- `Artifacts/FourCities/Native/four-cities.json`: 실제 Windows 플레이어의 시설 입구, 다층 계단, 승강기 운반, 수중 보행, 직원 안내, 배팅/정산, 탑승 주기, 적 공격, 영화 재생, 연출 및 지도 검사.
- 시각 검수에서 발견한 영화관 관람 위치 덮어쓰기, 새 지역 이동 직후 렌더러 표시 지연, 유리 반사/해수면 하부 표현, 주변 빈 부지와 지도 원형 영역 클리핑을 수정했다. 후속 캡처는 `Artifacts/FourCities/Visual`.

빌드와 검사 최종 결과는 `validation.json`에 기록한다. 원본 영화 제작기 `Tools/FourCities/create_cinema.py`, Blender 씬/렌더 로그는 `Artifacts/FourCities`에 남긴다.

최종 Windows 빌드: 오류 0 / 경고 46. 규칙 25개, 최종 네이티브 층 이동 59개와 표현/캠페인 18개 검사 전부 통과. `Screenshots`에 실제 플레이어에서 촬영한 지도·연출·영화관·축구장·수중도시 화면을 보관했다.
