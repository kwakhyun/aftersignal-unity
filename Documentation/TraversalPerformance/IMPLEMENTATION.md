# 튜토리얼 식별·표면 로프·프레임 부담 완화

2026-09-09. 기존 로컬 작업을 유지했다. 이번 요청에는 커밋·푸시가 없다.

## 튜토리얼

ThreatOverlay의 전역 진영 검색을 제거하고 현재 main01 전투에 실제 등록된 생존 전투원만 표시한다. 경찰·군인·일반 갱단·몬스터·장치는 표시 대상이 아니며 작전 종료 시 표시가 사라진다. NPC 전체 순회/거리 정렬도 없어졌다.

첫 임무의 임시 엄폐물 및 두 번째 단계의 소거 장치 3개를 제거했다. 두 번째 단계는 남은 회수대를 물리치고 대피로를 확보하는 전투로 교체했다. 대사·목표도 함께 변경해 사라진 장치 때문에 진행이 막히지 않는다. 다른 캠페인의 장치 파괴 임무는 유지한다.

## 로프

오른쪽 버튼을 누르면 카메라 조준점의 실제 충돌 표면에 로프를 건다. 탐험 범위는 110m이며 건물, 구조물, 차량, 이동 플랫폼을 지원한다. 가까운 벽을 통과하거나 빈 하늘에 걸리지 않도록 플레이어에서 연결점까지도 검사한다. 차량/플랫폼은 해당 콜라이더의 로컬 연결 좌표를 보존하므로 움직임과 회전을 따라간다. 대상 콜라이더 비활성화/삭제 또는 경로 차단 시 해제한다.

W/S 감기·풀기, A/D 횡방향 힘, SPACE 도약, 버튼 해제 후 관성 이동을 유지했다. 기존 축전기 등 캠페인의 명시적 앵커도 사용할 수 있다. 미리보기와 연결점은 두 개의 재사용 오브젝트이며 프레임마다 생성하지 않는다. 조준 레이 검사는 물리 서브스텝 수와 관계없이 화면 프레임당 한 번 수행한다. 충돌체가 없는 순수 시각 효과에는 연결하지 않는다.

## 성능

- 성능 프리셋을 일회성 기본값으로 적용한다. 이후 사용자가 선택한 품질은 유지한다. 85% 내부 해상도, SMAA, 65m/1024 그림자/2캐스케이드, 중복 MSAA 제거. UI는 원래 해상도다. 기존 고품질 설정의 주기적인 6면 실시간 반사는 최고 품질에서만 20초 이상 간격/128 해상도로 사용한다.
- 일반 시민 생성은 프레임당 2명·1.5ms 예산으로 분산한다. 가족 3명은 다른 생성이 없는 프레임에 함께 허용한다. 성능 프리셋의 180m 주변 이동 시민 상한은 150명, 스포츠 관람객 목표는 최대 156명이다. 선수·구조/치안 인력의 필수 행동은 유지한다.
- NpcGroundSupport는 갱신 시간이 되기 전 컴포넌트 검색을 하지 않고, 정지한 인물의 재검사 간격을 늘린다. 원거리 보정은 프레임당 18명/1.2ms 예산으로 나눈다. 벽 속 복구 지점 탐색은 한 번에 32곳 대신 반경을 순환하며 8곳씩 검사한다. 근거리 지면 복구는 유지한다.
- 보행 조향의 중복 캡슐/바닥 검사를 제거하고 거리별 일반 행동 갱신 간격을 조절한다. 차량 접촉 보정은 명시적 현재 위치를 받는 ComputePenetration을 사용해 차마다 최대 3번 수행하던 전체 Physics.SyncTransforms를 없앴다.
- 일반 승용차처럼 자식 오브젝트에 차체 충돌체가 있는 모델도 실제 차체 충돌체와 그 위치로 접촉을 보정한다. 긴 프레임 직후 물리 시뮬레이션을 과도하게 따라잡지 않도록 maximumDeltaTime을 0.08초로 제한했다.
- TrafficSpatialIndex는 차량 간 앞차 검색을 0.15초마다 갱신하는 공간 격자로 공유한다. 일반 차체 크기 조회의 반복적인 선박 컴포넌트 검색도 제거했다.
- 일반 교통 추가 생성은 한 번에 4대 대신 1대, 초기 32대는 프레임별로 분산한다. 성능 모드의 일반 운행 차량 목표는 32대다. 지역 장식은 한 번에 1곳 생성/최대 2곳 회수한다.

지면·도로·건물 렌더러를 비활성화하거나 월드 바닥을 컬링하는 변경은 없다. 모든 도시의 구조물을 새로 생성하거나 에셋을 일괄 재임포트하지 않았다. BGM/API 설정은 수정하지 않았다.

## 검증 방식

별도 숨김 실행 프로세스로 저장을 억제하고 실제 튜토리얼 생성/표시, 표면 연결/상승/관성/차량 추종/해제, 지면 보정/차량 접촉을 확인한다. 동일한 CrowdPerformanceProbe의 시내·경기장 시점을 변경 전/후 실행한다. 이 수치는 GPU readback을 포함한 진단 프레임 시간이며 실제 게임 FPS와 동일하지 않다. 품질 프리셋·군중 상한을 함께 낮춘 결과이므로 동일 화질의 순수 코드 성능 향상으로 해석하지 않는다. Mono의 할당 카운터 0은 측정 불가다.

전체 캠페인 완주와 장시간 대규모 교전 부하 검증은 수행하지 않았다.

## 결과
