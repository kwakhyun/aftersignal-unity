# 타이틀 3인 원화 · 로고 개선

- 기존 7인 합동 원화를 서하·노아·이솔 3인 구도로 교체했다. 서하는 상체와 골반이 같은 방향을 향하는 자연스러운 서 있는 자세이며 두 조연을 뒤쪽에 배치했다.
- 이미지 좌측에 `AFTER / SIGNAL` 전용 로고를 포함했다. 기존 타이틀의 중복 영문 제목과 상단 장식 문구를 제거하고 한국어 부제·실제 메뉴를 유지했다.
- 원화·로고·메뉴가 1600×900의 동일한 기준 프레임을 공유한다. 다른 화면 비율에서는 어두운 여백을 사용하여 인물과 로고가 잘리지 않게 했다. 원화 UV 이동을 제거하고 어두운 그라데이션을 메뉴 아래쪽으로 제한해 로고의 밝기를 유지한다.
- 원본 생성 프롬프트 및 참조 이미지는 `PROMPT.md`에 기록했다. 생성 결과는 Unity Resources의 기존 경로에 직접 적용했다.
- `TitleSmoke`의 `-title-artwork-only` 옵션은 타이틀만 캡처하고 종료하며 새 게임·이어하기 전환이나 플레이어 저장값 변경을 수행하지 않는다.

실행 대상: `Builds/TitleTrio/AFTERSIGNAL.exe` (`PLAY.cmd`가 최신 빌드 경로를 읽음).

빌드 및 타이틀 표시 확인 결과는 같은 디렉터리의 JSON 파일과 실제 타이틀 캡처를 참조한다. 이번 변경에서는 전체 게임 플레이 검증을 반복하지 않는다.
