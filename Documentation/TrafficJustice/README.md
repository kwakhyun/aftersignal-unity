# 차량 내구도·범죄 대응·시설 현금 — 2026-09-08

실행: 루트 `PLAY.cmd`. 빌드 대상은 `Builds/TrafficJustice/AFTERSIGNAL.exe`이며 런처가 `Builds/active-player.txt`를 읽는다.

## 조작

- 탑승 중 **B**: 크락션. 근처 시민이 대답하거나 비키며, 교통 차량은 정체 및 주변 경적에 반응한다.
- 일반 차량·바이크 탑승 중 **마우스 왼쪽**: 사격, **R**: 장전. **3** 권총, **4** 소총, **7** 샷건. 보유 무기와 실제 탄약을 사용한다. 전차·전투 항공기는 기존 전용 무장을 유지한다.
- **C**: 탑승 1인칭/3인칭 전환. 1인칭 창문에 Structural Glass 투명 셰이더를 사용한다.
- 수배 중 경찰 근처에서 **H를 약 1.4초 유지**: 투항. 경찰이 근접 제압을 일정 시간 유지해도 체포된다. 사망은 체포로 처리하지 않는다.
- **ESC → 집으로 복귀**. 추격·신고 진행·수감 중에는 사용할 수 없다.
- 집 금고, 은행 금고, 매장 현금함 앞에서 **E**. 집 금고는 500/5,000 C 또는 전액을 넣고 꺼낼 수 있으며 보관금은 저장된다.

## 내구도와 손상

| 탈것 | 최대 차체/선체 체력 |
| --- | ---: |
| 바이크 | 600 |
| 일반 승용차·택시·스포츠카 | 1,000 |
| 경찰차 | 1,400 |
| 버스 / 트럭 | 2,200 / 2,800 |
| 특공대 장갑차 | 6,500 |
| 보트 / 대형 화물선 | 7,000 / 50,000 |
| 여객기 / 전투기 | 18,000 / 10,000 |
| 전투헬기 / 경찰 추격 헬기 | 6,000 / 4,000 |
| 전차 | 24,000 |

기존 0–100 체력 저장은 비율을 보존해 새 용량으로 변환한다. 수리는 해당 탈것의 최대 체력까지 복구한다. 가벼운 접촉은 작은 손상이며, 도로 충돌 1회의 차체 피해 상한은 최대 체력의 8.5%다. 강한 충돌을 반복해도 먼저 연기·불 단계에 도달한다. 충돌 시 탑승자 1회 피해는 자동차 최대 12, 바이크 최대 24다. 폭발 때 탑승자를 즉사시키던 처리는 제거했고 탈출 직후 짧은 충격 보호를 적용했다.

잔여 체력 50% 이하에서 연기, 25% 이하에서 화염과 조명을 표시한다. 여객기·전투 항공기는 동력 상실 후 낙하·회전하다 충돌 시 폭발한다. 보트는 약 32초, 대형 화물선은 약 65초 동안 기울며 침몰한다. 이때 자동 항로와 NPC 조종을 중지한다. 일반 차량 폭발은 기존 파편 및 주변 범위 피해를 유지한다. NPC 사고의 폭발·승객 피해는 플레이어 범죄로 기록하지 않는다.

## 범죄 대응

시야가 확보된 경찰·군인은 즉시 범죄를 인지한다. 일반 목격자는 5초 신고를 완료해야 수배가 발생하며, 신고 도중 쓰러지거나 사라지면 해당 신고는 취소된다. 장애물 너머와 목격자 없는 장소에서 발생한 사건은 자동 수배로 전환하지 않는다.

수배 3단계부터 특공대 장갑차가 출동하며 뒤쪽 램프에서 4명이 순차적으로 내린다. 경찰차의 부자연스러운 텍스트를 제거하고 레드/블루 점멸 조명을 적용했다. 경찰 헬기는 지상의 서하 또는 탑승 차량을 서치라이트로 추적한다. 최근 연속 신고 범위에서 확인된 사망자 8명 이상이며 수배 5단계면 군용 트럭 2대·전차·전투헬기·전투기가 출동한다. 트럭별 군인 6명이 하차한다. 군부대에는 전차 8대, 전투기 4대, 전투헬기 4대를 추가 배치했다. 정문 위병소는 비수배 상태에서 4초 신원 조회 후 차단기를 연다.

경찰서에서 범죄가 발생하면 경찰 직원들이 무장 대응한다. 은행 금고는 12초 동안 가까이 있어야 8,000–18,000 C를 가져갈 수 있고 은행원이 신고한다. 병원·식당·카페·상점·호텔 현금함은 4초 뒤 350–1,500 C를 획득한다. 각 현금함은 게임 날짜별 한 번 탈취할 수 있다. 집 금고 입출금은 현금을 이동시키며 새 돈을 생성하지 않는다.

## 구현 범위와 확인

런타임 생성 장갑차·위병소·금고, 기존 전용 군인 스프라이트 및 전투 코드를 통합했다. 추락·침몰은 연출용 상태 이동이며 선체 부력·항공역학의 정밀 시뮬레이션은 아니다. 특공대/군 차량은 기존 도로 충돌·조종을 사용하므로 복잡한 장애물 우회에는 한계가 있다. 경적은 합성한 이중 음색이며 외부 오디오를 내려받지 않았다.

필수 Windows 네이티브 검증: `-traffic-justice-smoke`. 결과는 `Artifacts/TrafficJustice/Final/result.json`, 프레임은 동일 폴더, 빌드 기록은 `Artifacts/TrafficJustice/build-final.log`. 검증에서는 게임 진행·현금 저장을 억제하고 변경한 사이트/수감 환경설정을 복원한다. 최종 집계는 `validation.json`에 기록한다.
