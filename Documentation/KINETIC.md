# 서하 이동·차량 반응·클라이언트 조작

실행: 프로젝트 루트의 `PLAY.cmd`.

| 입력 | 동작 |
|---|---|
| WASD | 기본 달리기. 걷기 구분과 두 번 누르기 조건을 제거했습니다. |
| 마우스 이동 / 휠 | 중앙 조준점을 기준으로 3인칭 회전 / 확대·축소 |
| 1 / 2 / 3 | 카타나 / 대검 / 권총 |
| 마우스 왼쪽 / 오른쪽 | 공격 / 로프 |
| SPACE | 점프. 공중에서 한 번 더 누르면 더블 점프 |
| 벽을 향해 점프한 뒤 W | 외벽 붙잡기와 위로 등반 |
| 등반 중 A/D / S / SPACE | 옆으로 이동 / 놓기 / 벽 차고 도약 |
| E | 대화·시설 이용·승강기 호출 또는 층 이동 |
| J / M / ESC | 사건 일지 / 지도 / 일시정지·설정 |

서하는 일러스트의 작은 머리, 긴 팔다리, 날씬한 체형을 기준으로 새로 제작한 스프라이트를 사용합니다. 달리기는 8방향에 각 8단계, 무기 공격은 8방향에 무기별 4단계입니다. 정지·공중·등반 동작과 차량 안 서하도 새 체형으로 연결했습니다. 방향 변경 시 보폭의 진행 단계를 유지하고, 실제 이동 거리로 재생 속도를 계산합니다. 근접 판정과 권총 발사 위치, 검기 궤적도 조준 방향을 따릅니다.

차량 탑승자는 차량 상태에 따라 반응합니다. 주행 중이고 상태가 양호하면 가속해 도망치고, 정차·심한 손상·길막 상태에서는 내려 도망칩니다. 버스는 위험 상황에서 정류장 승하차를 중단합니다. 폭발한 차량 안 탑승자는 차량 밖에 쓰러져 나오며, 중복 생성하지 않습니다. 탑승 중인 서하 역시 폭발 피해를 받습니다. 경찰·갱단 탄환은 먼저 맞은 시민에게도 피해를 줍니다.

경찰차에는 전용 흰색·검은색 외장, 파란색 띠, POLICE·112 표식, 앞 범퍼 보호대, 경광등 받침과 무전 안테나를 적용했습니다.

아파트 6층 안전 바닥에서 승강로를 비워 하강을 막던 충돌을 수정했습니다. 다른 층에서 호출하면 해당 층으로 오며, 탑승 후 E를 누르면 반대 층으로 이동합니다.

HUD는 상호작용 카드, 무기 단축키와 선택 표시, 공중 추가 점프·등반 에너지·승강기 상태를 표시합니다. 대화·메뉴에서는 이동 안내를 숨기고, 해상도 비율에 따라 화면 공간을 확보합니다. 메뉴의 글자 강조와 조작 설명도 갱신했습니다.

이미지는 내장 image_gen 도구로 제작했습니다. 에셋: `Assets/AfterSignal/Resources/Art/SeoKinetic/`. 프롬프트와 출처: `Documentation/Art/seo-kinetic-prompts.json`. 원본은 보존하며 Unity 임포트 단계에서 배경과 프레임 여백을 정리합니다.

최종 Windows 빌드는 오류 0개로 성공했으며 경고 39개가 남아 있습니다. 필수 네이티브 실행 확인 23개가 모두 통과했습니다. 달리기·8방향 에셋, 이단 점프 제한, 외벽 붙잡기·상승·벽 차기·옥상 도착, 차량 대피·가속 도주·폭발 탑승자 처리, 경찰·갱단의 시민 피격, 경찰차 표시, 승강기 상하 왕복을 확인했습니다. 결과는 `Artifacts/Kinetic/Final/kinetic.json`, 빌드 기록은 `Artifacts/kinetic-final-build.log`입니다. 전체 캠페인 완주나 장시간 성능 검사는 이번 변경의 확인 범위에 포함하지 않습니다.
