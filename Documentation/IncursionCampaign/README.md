# 잠식 거신 · 출동 · 전투 캠페인

기존 변경사항은 `14a5ed78`로 main에 커밋하고 origin/main으로 푸시한 뒤 작업했다.

## 전투 피해

- 일반 충돌과 총탄의 기존 내구도는 유지한다. 미사일과 대전차 포탄만 별도 탄두 피해를 사용한다.
- 미사일 직격: 비장갑 차량 최대 체력의 135%, 장갑차 65%, 탱크 39%, 항공기 72%, 일반 선박 55%, 대형 화물선 28%. 대전차 포탄은 해당 비율의 80%다. 주변 폭압은 거리와 차폐에 따라 감소한다.
- 대형 선박은 중심점만으로 피격을 판정하지 않는다. 차체 충돌 지점과 직접 맞은 차량을 폭발에 전달한다.
- NPC가 발사한 탄두는 발사자 정보를 유지한다. 군·몬스터 공격을 플레이어 범죄로 계산하지 않는다.

## 범죄와 대응

빈 주차 차량에 탑승하는 행위는 신고를 만들지 않는다. 운전자를 끌어내는 점유 차량 탈취와 폭력의 목격·신고 규칙은 유지한다.

군 개입 기준은 목격·신고로 확인된 민간인 사망 30명 이상이며 수배 5단계일 때다. 사건이 3분간 끊기면 집계가 초기화된다. 경찰·군·갱·몬스터 사망은 이 민간인 집계에 넣지 않는다.

출동은 화면 밖의 도로상 합류점을 사용한다. 경찰서·군부대와 가까운 경로를 우선하며, 지상 차량은 사건에서 220~950 m, 항공기는 최소 650 m 떨어진 위치에서 등장한다. 모든 후보가 보이면 출동 생성을 미룬다. 차량은 공통 도로 경로를 따라 접근하며, SWAT는 약 24 m, 군 수송대는 40 m 안쪽에 도착한 뒤 후문으로 하차한다. 시간이 지났다는 이유로 원격 하차시키거나 보이는 차량을 순간이동시키지 않는다.

군 작전은 수송차 2대, 전차 2대, 전투헬기, 전투기를 순차 투입한다. 괴물 출몰은 44초, 대규모 범죄는 55초 동원 준비 뒤 출발하며 실제 이동 시간이 추가된다. 현재 방식은 각 시설의 개별 차고 문을 열고 나오는 완전한 물류 시뮬레이션이 아니라 도로 합류 방식이다.

네레이드 내부에서는 비행기 대신 추가 지상 장갑 지원대를 사용한다. 경찰은 첫 신고 뒤 12초, SWAT는 최소 20초, 경찰 헬기는 32초 이후 합류한다. 은신 해제 시간은 46~86초로 조정해 차량 접근 시간이 반영되도록 했다. 에레보스 지역 교전도 같은 동원 절차를 사용한다.

## 거신

Blender 원본, FBX, 부위별 관절을 가진 3종: 잔향의 도살자(이족), 철갑 포식자(사족), 공허의 예언자(육족). 피부·겹갑각·골질·발광기관 재질을 분리하고 관절별로 메시를 묶었다. 원본은 Models, 제작 스크립트는 Tools/WorldExpansion/create_rift_titans.py에 있다.

일반 개체 체력은 14,000 / 21,000 / 16,000. 외피가 닫히면 피해의 32%, 공격 준비 및 공격 직후에는 82%를 받는다. 미사일·포탄의 괴물 피해는 일반 폭발의 8배다. 시민을 우선 탐색하면서 대원·차량과도 싸운다. 광역 후려치기, 큰 지면 충격파, 충전 예고 후 대공 레이저를 사용한다. 레이저는 충돌체·차폐를 검사하며 헬기에 큰 피해를 준다.

모델의 FBX 좌표축 변환은 내부 모델 루트에서 보존하고, 이동 방향은 바깥 부모에서 회전시킨다. 모델 루트 회전을 identity로 덮으면 Blender의 위쪽 축이 사라져 거신이 누워 보이므로 유지할 것.

일반 도심에서는 첫 경보 35~65초, 종료 후 다음 사건까지 65~115초. 동시에 한 사건(대부분 1체, 매 세 번째 사건은 최대 2체)만 유지한다. 살아 있는 화면 내 괴물은 기존 210초 제한으로 사라지지 않는다. 10분 이상 지난 먼 사건만 정리한다.

## 시나리오와 대사

기존 main01~main30의 저장 식별자와 3단계 구조를 유지하면서 30개 작전/90개 전투 단계로 교체했다. 주민 납치 → 노바의 기억 회수망 → 에레보스 실험 증거 → 네레이드의 복원 키 → 도시 반격 → 공명로 격파로 연결된다.

현장 접근으로 교전이 시작된다. 돌파, 증폭기 3개 파괴, 일정 시간 거점 방어, 주민 호위, 탈출, 대형 보스전이 결합된다. 목표 수와 방어 시간은 전투 HUD에, 이야기와 다음 행동은 짧은 교신 자막에 표시한다. 전투 단계 완료 시 회복과 자동 다음 단계, 작전 완료 시 보상과 다음 작전 추적을 제공한다. 기존 완료 기록과 보상 기록은 보존하고, 진행 중 단계의 새 현장으로 안내한다. 주민 서브 의뢰는 유지한다.

공통 바닥 탐색은 절대 고도 0m 제한을 없애고 요청 위치의 높이를 기준으로 한다. 수중 도시에서도 경비대·구조 NPC를 생성할 수 있다. 먼저 정확한 요청 좌표를 검사한 후 주변 후보를 검사해, 이동 NPC가 매 프레임 옆으로 밀리지 않도록 했다. 호위는 장애물 경로를 사용하며 플레이어가 16m 안에서 이끌 때 따라간다.

StreetVoices에 상황 대사 188개를 더해 총 552개다. 괴물·출동·신고·충돌·차량 대피·경적과 일상 대화에 연결했다. 주요 역할에는 별도 위기 말투가 있다.

## 필수 확인

`IncursionCampaignSmoke`는 `-incursion-smoke`로만 실행된다. 피해와 범죄 귀속, 출동 경로·하차, 거신 크기·레이저·민간인 타격, 메인 전투 지점 바닥, 첫 작전의 세 단계 및 다음 의뢰 진행을 실제 Windows 플레이어에서 확인한다. 실행 결과는 validation.json, 화면은 Artifacts/IncursionCampaign/Native에 기록한다.

빌드 대상: Builds/IncursionCampaign/AFTERSIGNAL.exe. PLAY.cmd는 빌드 완료 후 활성 플레이어 설정을 통해 해당 실행 파일을 사용한다.

최종 결과: 기능 실행 확인 57항목, HUD 표시 확인 3항목 통과. 런타임 오류 0건. 모든 작전의 바닥은 확인했고, 첫 작전은 돌파→장치 파괴→호위 완료→다음 작전 추적까지 실행했다. 30개 작전 전체를 수동 완주한 결과는 아니다. UI 수정 후에는 관련 표시만 다시 확인했다.
