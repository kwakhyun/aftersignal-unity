# 도시 무장 조직과 통합 재난 대응

이 작업 전 변경사항은 main의 `61e34d8d`에 보관하고 origin/main에 푸시했다.

## 변경 범위

- 운전 중 조작 설명은 문맥 카드 한 곳에 표시하고 속도·연료·내구도는 별도 계기 줄로 표시한다.
- 차량 탑승자와 하차자는 같은 4방향 인물 아틀라스를 공유한다. 경찰 세단에는 세단 좌석 좌표를 적용한다.
- 보행자 풀 외의 경찰·군인·시설 NPC도 차량의 이동 구간과 차체 크기를 이용한 충돌 판정을 받는다.
- 갱단과 경찰의 4방향/4포즈 이미지 교체. 원본은 `SourceArt`에 보존하고 게임용 이미지를 실제 RGBA로 변환한다. `CyberSecurityImporter`가 연결된 배경을 제거하고 발 피벗을 맞춘다.
- 별도 FBX 군용 수송차, 갱단 습격차, 경찰 진압 로봇, 군용 전투 로봇. 로봇은 관절별 이동 애니메이션, 탐색, 사격과 파괴 처리를 갖는다.
- 기존 도시의 빈 필지에 세 조직의 작은 아지트를 배치한다. 무기 공방·탄약고·통신실·계단·중층을 만들며 새 땅을 추가하지 않는다.
- 아지트 주변 경비대와 무장 차량의 습격, 순찰차·특수대응 장갑차의 단계적 출동. 거리는 출동 차량이 실제로 주행한다.
- N-17의 납치·기억 거래를 무장 조직의 공방과 서버, 호송망에 연결하는 메인 작전 3개/전투 단계 9개 추가. 기존 의뢰 ID와 완료 기록을 유지한다.
- 직업과 연령에 따른 일상·충돌·위기·출동 대사와 직업별 대화 쌍. 구조대원과 교전 중 전투원은 잡담하지 않는다. 경찰과 군인은 전투 임무를 수행하며 시민은 피한다.
- 몬스터 이름·체력·공격 예고, 지면 파편·균열 광선·충격파와 거리별 카메라 흔들림. 최근 자신을 공격한 상대의 위협도를 추적한다.
- 잠식 재난 동안 수배 상태는 보존하고 추격보다 몬스터 진압을 우선한다. 경찰·특수대응팀·군인·전투 로봇이 지원한다.
- 부상 상태는 시민·경찰·군인에 공통 적용한다. 전투 불능자는 기존 인물 상태를 유지하고 지원을 요청한다. 두 구급대원이 들것으로 옮기고, 구급차에 싣고 가까운 정상 운영 병원으로 이송·치료한다.

## 제작과 실행

이미지는 이 프로젝트를 위해 생성한 원본이다. 프롬프트는 `ART-PROMPTS.md`에 기록한다. 차량·로봇은 외부 게임 모델을 복제하지 않은 자체 제작 메시다.

모델 재생성: Blender 4.5에서 `Tools/WorldExpansion/create_security_units.py` 실행. 모델과 재질별 정적 파트를 묶고 관절·바퀴·후방 램프는 유지한다. 작업 원본과 검토 렌더는 `Artifacts/CyberConflict/Models`에 남긴다.

실행: `PLAY.cmd` → `Builds/CyberConflict/AFTERSIGNAL.exe`.

필수 실행 검증: `-cyber-conflict-smoke -quality-output Artifacts/CyberConflict/Final`. 저장 데이터는 검증 동안 기록하지 않는다. 결과는 해당 폴더의 `result.json`과 실행 캡처에 기록된다. 최종 확인 기록은 `validation.json`을 참고한다. 전체 33개 메인 작전을 수동으로 완주한 검증은 아니다.

입력키는 기존 설정을 유지한다. 신규 메인 작전은 J 의뢰 일지에서 선택한다. 구조와 재난 지원은 현장 상태에 따라 자동 작동한다.
