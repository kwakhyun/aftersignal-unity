# 인물·길 안내·현장 판단 개선

2026-09-09. 기존 로컬 작업과 BGM/API 설정을 유지했다.

## 이미지

- 서하 상반신 초상화를 StoryCast의 애니메이션풍 선화·청록 조명에 맞춰 새로 제작했다. `Art/Portraits/SeoDialogue.png`를 사용하므로 기존 대화 UI에 바로 연결된다.
- 타이틀은 서하·노아·해진·이솔·나리·세린·다은 7인(여성 6인) 합동 원화로 교체했다. 왼쪽 메뉴 영역을 비워 두었다.
- StorySprites의 11개 시트는 각각 2명, 인물당 4방향 × 정지/걸음 두 접지/대화 = 16프레임이다. 총 22명, 352프레임. 발 기준점과 화면상 높이를 정규화하고 크로마 키를 임포트 시 제거한다.
- 기존 이름을 가진 주요 등장인물에만 전용 시트를 적용한다. 무작위 시민이 동명이인이라는 이유로 주연 외형을 사용하는 것은 막았다. 네 도시 캠페인의 대면 협력자는 해당 시설/층에 실물 NPC를 배치했다.
- 생성 프롬프트·원본 경로는 `art-prompts.json`. 도윤/시장상인·라온/윤 시트의 잘린 발과 라온의 잘못된 의상은 재생성으로 교정했다.

## 이동과 피격

NpcGroundSupport는 마지막 안전 위치와 현재 위치 사이의 이동을 검사한다. 벽 앞에서는 축별 이동 또는 이전 지점으로 복구하고, 바닥 밑으로 떨어진 경우 안전 층으로 돌려놓는다. 스폰 지점이 벽 안이면 짧은 반경 내의 빈 바닥을 찾는다. 승강기·층간 이동과 큰 명시적 순간이동은 별도로 착지를 검증한다. 차량 내부·들것 운반·능동적인 충돌 비행 중에는 이 보정을 사용하지 않는다.

중상자의 피격 박스는 빌보드와 독립된 자식 오브젝트로 옮겨 지면에 맞춘다. 바닥의 환자 이미지는 실제 수평으로 표시하고 들것의 환자 이미지와 구분한다. 서 있는 중복 트리거가 카메라 회전에 따라 뒤집히는 경우도 배제한다. 플레이어와 진영 사격은 동일한 유효 충돌 필터를 사용해 대화/AI 트리거와 깨진 유리의 열린 영역을 통과한다.

## 역할별 판단

TacticalJudgment는 활성 여부, 사망/중상, 진영, 차량의 승무원/파괴 상태, 가시선과 첫 피격 대상에 따라 발사를 허용한다. 경찰은 무효 출동 표적·예약 연사를 즉시 취소하고 12초간 보이지 않은 비플레이어 출동 표적의 수색을 종료한다. 시민/아군이 사선을 가리면 발사를 보류하고 측면으로 이동한다. 군인은 짧은 점사와 사선 확보, 저체력 측면 이동을 사용한다. 갱단은 사라진 목표를 버리고 유효한 사람을 재탐색한다. 지역 경비원·경찰서 직원·전투 로봇에도 같은 표적 유효성/사격 판단을 적용했다.

구급대는 환자와 접근 경로 주변의 가까운 위협을 감지하면 접근을 잠시 보류하고 경찰 엄호를 요청한다. 위협이 사라지면 2초 후 처치를 계속한다. 들것과 구조대 이동도 바닥·장애물 경유 검사를 거친다. 소방대는 화점 주변의 실제 서 있을 수 있는 방수 지점을 찾고, 적의 접근 시 경찰 엄호를 요청하면서 소방차 쪽으로 이동한다. 매 프레임 외부 AI API를 호출하지 않는 로컬 상태 판단이며, 의료·소방 출동 상한 5대는 그대로 유지한다.

## 지도와 길 안내

지도는 북쪽 고정이며 현재 시선의 삼각 화살표와 8방위/방위각을 보여 준다. 장소·임의 지점 클릭으로 목적지 설정, 목적지로 화면 이동, 우클릭/버튼 안내 해제를 제공한다. 임의 수중 목적지는 도시의 지면 높이를 적용한다.

길 안내는 도로 그래프의 경로를 추적하고 다음 회전·남은 경로 거리·대략적인 시간·도착을 표시한다. 경로 이탈 또는 45m 이동 시 재탐색하며, 매 0.5초 전체 A*를 다시 실행하던 비용을 줄였다. 도로 연결이 없거나 항구 교통편이 필요한 구간은 별도 안내한다. 공중에 길게 이어진 단일 선 대신 가까운 지면 위에만 최대 28개의 화살표를 하나의 메시로 그린다. 실제 교통 혼잡까지 반영한 ETA나 모든 실내 층의 NavMesh 탐색은 아니다.

## 확인

`-cast-navigation-probe`는 별도 플레이어 프로세스에서 저장 데이터를 쓰지 않고 이미지 리소스, 벽/바닥 보정, 경찰 사격 중단, 누운 환자 피격, 구조대 위험 판단, 경로/도착과 실제 UI 캡처를 확인한다. 결과와 캡처는 `Artifacts/CastNavigation/Native`에 기록된다. 전체 캠페인 완주/장시간 부하 검증은 범위에서 제외했다.

핵심 실행 확인 16개 모두 통과했고 실행 오류는 0이었다(`functional-result.json`). 최종 길 안내 카드 위치 조정 후에는 UI 전용 옵션 `-cast-navigation-ui`로 리소스/표시 4개만 확인했으며 모두 통과, 실행 오류 0이었다(`presentation-result.json`). 길 안내 카드가 무기 선택 UI 위에 분리되어 있는지와 실제 도시 배경의 대화·지도·타이틀을 캡처로 확인했다. 숨김 플레이어의 UI 캡처는 화면 오버레이를 임시 카메라 캔버스로 렌더하므로 실제 오버레이보다 텍스트/인물 가장자리에 후처리가 적용되어 보일 수 있다.

최종 Windows 빌드: 성공, 2,179,277,115바이트, 오류 0, 경고 90개. `Builds/active-player.txt`는 `Builds/CastNavigation/AFTERSIGNAL.exe`를 지정한다. 기존에 실행 중이던 게임은 유지했으므로 변경 확인 시 해당 게임을 종료하고 `PLAY.cmd`로 새로 실행해야 한다. 이번 작업은 커밋·푸시하지 않았다.
