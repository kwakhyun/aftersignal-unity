- VRoid에서 키·머리·어깨 비율, 눈매와 보라색 눈, 은보라색 머리, 검은 상의·팬츠·부츠를 편집했습니다.

- 짧은 왼쪽 소매, 긴 오른쪽 소매, 크롭 상의, 접힌 칼라·라펠, 지퍼 이빨, 벨트·파우치, 귀걸이, 손목 장비를 만들었습니다.
- VRoid가 원래 긴 소매 아래에서 제외한 왼쪽 위팔 메시를 기존 팔 경계에서 연장하고 가중치와 불투명 피부 영역을 복원했습니다.
- 원래 의상의 회로·원형 무늬를 가죽 주름과 봉제선 도색으로 바꿨습니다. 도색 결과의 배경은 RGB 체크무늬이므로 원본 실루엣 알파를 유지하고 밝은 경계 패딩은 재질에서 억제합니다. 투명 PNG를 생성했다고 주장하지 않습니다.
- **117개 뼈대**와 손가락 리깅을 유지했습니다. 팔을 내린 자세, 눈 감기, 발음, 팔꿈치·무릎 굽힘을 실제 렌더로 확인했습니다.

## 품질 평가

새 기반은 기존 수식 기반 얼굴보다 눈꺼풀·입 안쪽·손가락·표정 연결을 편집하기 좋습니다. 이 점이 원화급 외형이나 최종 게임 애니메이션 완성을 뜻하지는 않습니다.

남아 있는 차이:

1. 두상과 눈매의 개성, 머리카락 가닥의 자연스러운 묶임과 낮은 묶음 연결이 아직 원화와 다릅니다.
2. 칼라·라펠 곡면은 수정했지만 일부 의상 경계와 장비가 여전히 단순합니다. 재단·주름·재질의 세부 제작이 더 필요합니다.
3. 손가락 접촉, 어깨·손목과 의상의 큰 동작 변형, 모발 물리 충돌을 최종 검수하지 않았습니다.
4. 달리기·공격·운전·수영 등 완성된 게임 동작 세트를 제작하거나 Unity에 연결하지 않았습니다. 현재 포즈는 변형 시험입니다.
5. 다수의 제작용 메시를 분리해 두었습니다. 게임용 메시 병합·재질 베이크·LOD·런타임 프로파일링은 후속 단계입니다.

`rig-review.json`의 수치나 저장 성공은 미술 품질 합격 판정이 아닙니다. 인게임 코드·Windows 빌드는 이번 작업에서 변경하지 않았고, 게임 전체 테스트는 실행하지 않았습니다.

## 재현

로컬 VRoid 원본과 VRM, 두 도색 텍스처, Blender 4.5.3 및 VRM Add-on 4.7.1이 필요합니다.

1. `import_vroid.py`: 로컬에서 직접 만든 VRM을 가져와 원본과 가져오기 보고서 저장.
2. `refine_vroid.py`: 새 기반 위에서 조형·의상·재질 수정 및 정면/사선/측면/전신 렌더.
3. `review_vroid_rig.py`: 장갑, 포즈·표정 변형 검수와 최신 편집 원본 저장.
4. `sculpt_likeness.py`: `seoha_deformation.py`의 얼굴·체형 변형, 복부 부분 세분화와 기본 뼈대 보정. `-- --no-render`는 중간 단계 렌더를 생략합니다.
5. `finish_anatomy.py`: 옆 가르마 모발·의상 곡면·피부 음영·벨트 보정 및 다각도 렌더.
6. `review_anatomy.py`: 필수 구조 검사, 중립/표정/관절 검수와 최신 `Seoha-Anatomy-Review.blend` 저장.

각 스크립트는 `Tools/SeohaStudio/`에 있으며 Blender의 `--background --python`으로 실행합니다. `vroid_review.py`는 검수 렌더마다 조명을 정리하여 반복 실행 시 과다 노출되지 않게 합니다.

이전 MakeHuman/MPFB 스터디와 불합격 TripoSR 결과는 이전 연구 자료로 보존했습니다. 최신 기본 제작본은 이 문서의 VRoid 기반입니다. [도구 검토 이력](tool-evaluation.md), [명조 참고 관찰](wuthering-waves-reference.md).
