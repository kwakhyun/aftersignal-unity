위 항목은 공식 영상을 브라우저에서 정지해 관찰한 **외관 분석**이다. 실제 개발팀의 토폴로지·셰이더·리깅 구현을 확인한 것은 아니다. 내부 기술을 그대로 재현했다는 의미가 아니다.

서하의 얼굴, 보라색 눈, 은빛 라벤더 머리, 낮은 측면 묶음, 비대칭 검은 재킷과 청록색 장비는 프로젝트 원화를 기준으로 유지한다.

## 검수 범위와 적용 상태

Blender에서 만든 실제 메시를 정면·사선·측면·전신으로 렌더해 반복 비교했다. 구조 검사와 동작 스터디는 미술 품질 합격을 뜻하지 않는다.

**명조나 서하 원화 수준의 최종 모델로 승인하지 않았고, 게임에는 적용하지 않았다.** 다음 차이가 남아 있다.

- 일부 모발 층과 묶음이 여전히 규칙적이고, 뿌리의 겹침과 잔머리를 더 섬세하게 정리해야 한다.
- 얼굴은 표면 전용 알베도와 얕은 눈 곡면을 사용한다. 완전한 안구·눈꺼풀·입 내부 구조와 표정 리깅은 아직 없다.
- 재킷의 접힘, 장갑·손가락의 접촉, 무기 그립, 동작 중 의상 관통은 추가 제작이 필요하다.
- 스튜디오 세분화와 많은 개별 메시를 사용한다. 최종 게임용 메시 정리, 재질 베이크, Unity 조명에서의 확인은 아직 하지 않았다.

이번 단계에서는 게임 코드·실행 파일을 바꾸지 않았다. `.blend`, 텍스처, 렌더는 비공개 `Artifacts/SeohaStudio`에 저장한다.
