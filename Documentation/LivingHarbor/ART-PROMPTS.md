# Civic forces — original sprite sources

Generated with the built-in image generator. Source images are preserved in `SourceArt/`; runtime RGBA imports and 16 directional poses are in `Assets/AfterSignal/Resources/Art/CivicForces/`. The generator rendered a checkerboard matte, so the existing Unity connected-background import pass removes the matte before packing. Authored vessels use `Tools/WorldExpansion/create_maritime_fleet.py` (Blender).
