# 카메라 복구 · 도시 선택 리스폰 · 교통/군 대응

실행: `PLAY.cmd` (활성 빌드: `Builds/DefenseMobility/AFTERSIGNAL.exe`).

## 플레이 변경

- 보행·일반 이동에서는 기존 45도 화각, 어깨 주시점, 위치 보간에 맞춘 시점 회전을 복구했다. 확대 화각·주인공 근접 숨김·추가 벽 침투 보정은 벽 등반 상태에만 사용한다. 마우스 회전과 휠 줌은 유지한다.
- 사망 화면에서 애프터라이트(서하의 집), 노바(응급의료센터), 에레보스(전진기지 의무실), 네레이드(생명지원센터)를 선택한다. 기본 선택은 서하의 집이다. 다른 도시는 지형과 시설 생성 완료 후 바닥을 확인하고 리스폰한다. 새 게임·이어하기의 집 시작 규칙은 유지한다.
- 플레이 HUD에서 미장착 무기 단축키 목록을 제거했다. 장착한 무기의 이름·아이콘·탄약은 기존 패널에 표시한다.
- 차량 경로에 건물이 있으면 실측 충돌과 지면을 검사하는 제한된 A* 탐색으로 우회한다. 일반 차량과 긴급 출동 차량 모두 사용하며, 긴급 출동은 기존 양보·교통규칙 우선 통과를 유지한다. 도로 연결 탐색은 최소 힙을 사용한다.
- 여객선, 화물선, 수상택시, 함정은 공통 선박 목록과 선체 크기를 사용한다. 항로 회피, 회전 선체 분리, 연속 이동 중 선체 통과 방지를 추가했다. 직접 조종하는 배는 조작 방향을 유지하며 충돌만 제한한다.
- 육군·해군·공군 및 지역 군사시설의 기존 병력이 인근 위협을 발견하면 지원 사격하고, 위협 해소 후 복귀한다. 비전투 루틴과 전투 이동이 동시에 작동하지 않는다. 테러는 기존대로 경찰 대응에 맡긴다.
- 루멘 방위기지, 해군기지, 공군기지에 무기고를 배치했다. 진열대에서 E를 누르면 해당 무기를 장착하고 탄약을 보급한다. 검·대검·권총·소총·수류탄·로켓·산탄총의 총 13개 장비를 제공한다. 군사시설 보급 메뉴에서도 장비를 선택할 수 있다.
- 공군 기지에 옵시디언 폭격기 2대를 배치했다. 전용 비행익 메시, 동체·날개 충돌, 2인 조종석, 투하창, 공군 승무원을 적용했다. WASD 비행, SPACE/CTRL 상승·하강, C 시점, 우클릭 24발 연속 투하, 착륙 후 R 8초 재보급. 적재량은 96발이다.
- 폭격기는 자동 폭격 항로와 중력을 고려한 투하 지점을 사용한다. 폭탄은 실제 비행 속도를 이어받아 낙하하고 지면/구조물 충돌 시 폭발한다.
- 에레보스의 잠식 사건 하나에 최대 5마리의 몬스터가 서로 떨어져 출현한다. 증원은 트럭 4대(병력 최대 24명), 전차 7대, 헬기 5대, 전투기 3대, 폭격기 2대다. 준비 30초 이후 약 7초 간격으로 출동한다. 일반 도시의 기존 규모와 44초 준비 시간은 유지한다.

## 연산 범위

사건 시작 240m, 전투 420m, 사건 정리 550m 기준을 유지한다. 기존 도입 임무 보호와 단일 사건 제한도 유지한다. 주둔군 탐색은 공간 인덱스에서 0.8초 간격으로 수행한다. 차량의 지역 A*는 한 프레임에 1회, 최대 850개 노드로 제한하고 결과를 재사용한다. 비행 폭탄은 전역 최대 72개다. 건물 충돌이나 바닥을 끄는 방법으로 우회하지 않는다.

## 필수 확인

최종 Windows 빌드 성공: 오류 0, 기존 경고 91. 네이티브 기능 확인 29개 통과, 실행 오류 0.

`-defense-mobility-probe`에서 저장하지 않는 별도 실행으로 카메라/사망 UI/도시 재진입/실제 차량 우회/군인 사격·복귀/선박 분리·통과 방지·회피/무기고/폭격/몬스터 군집을 확인한다. 결과는 `result.json`, 최종 빌드는 `build-result.json`을 참고한다.

모든 도시의 모든 교차로·내부와 장시간 대규모 교전 전체를 전수 검증하는 검사는 수행하지 않는다. 불가능한 통로에서는 차량이 정지 후 재탐색하며, 벽을 통과하거나 순간이동하지 않는다.
