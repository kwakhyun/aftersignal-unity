# 도시 안전 행동과 충돌 보완

2026-09-09. 이전 변경사항을 유지하며 이번 요청을 추가 적용했다.

- NPC 차량이 보행자를 치면 차량 자체에 사고 기록이 생성되고 3초 뒤 경찰차 두 대가 시야 밖 도로에서 출동한다. 서하의 수배 기록과 분리되며, 순찰차가 따라붙으면 운전자가 정차하고 기존 탑승자 외형을 유지한 채 내린다. 동시 사고 추격은 두 건까지이며 재난 진압이 우선이다.
- 서하는 마지막 피해로부터 8초가 지나면 초당 2.5 HP를 최대 체력까지 회복한다. 일시정지·사망 중에는 회복하지 않는다.
- 해안의 논리적 물 영역을 실제 모래 해안에 맞췄다. 잠수 중에는 육지 밑 진입을 차단하고 수면 가까이에서는 안전한 해안 위로 올라선다. 이미 땅 밑에 있는 플레이어도 복구하며 수중도시의 건조 공간과 전용 진입 경로는 허용한다.
- 고층 건물의 좁은 내부 코어 충돌을 실제 외벽·기단·상층 후퇴 형태를 따르는 낮은 복잡도의 충돌 메시로 교체했다. 건물마다 하나의 정적 충돌 메시를 사용하고 쌍둥이 빌딩 사이 빈 공간은 유지한다.
- 폭발·몬스터 충격파는 차량 충돌과 분리해 군인·경찰의 수평 이동을 약 8m 이하로 제한한다. 공중에서 반복 충격으로 속도가 누적되지 않으며 실제 고속 차량 충돌의 강한 넉백은 유지한다.
- 잠식체 출동 편성은 탱크 4대, 전투헬기 3대, 전투기 1대, 병력 트럭 2대다. 기존 대기 시간과 순차 출동을 유지한다. 수중에는 항공기를 투입하지 않는다.
- 잠식체가 260m 안의 탑승 중인 항공기를 예고 후 중력 소용돌이로 자기 앞으로 끌어당긴다. 항공기 조종·자동항로를 일시 중지하고 추락 상태로 전환한다. 포획 전에 멀리 벗어나거나 끌어당기는 중 잠식체를 처치하면 중단된다. 서하는 포획 중에도 F로 탈출할 수 있다.
- 소방차는 실제 소방서를 기준으로 출동한다. 방수 시야가 막히면 위치를 바꾸며 호스 담당과 구조 담당이 분업한다. 구조 담당은 시민을 대피시키고 중상자를 들어 안전한 장소로 옮겨 안정화·구조 신고한다. 경상자는 응급처치한다. 이미 출동한 구급대는 소방 구조가 끝날 때까지 기다렸다가 인계받는다. 소방차는 구조와 승무원 복귀를 기다리고 최대 5대 제한을 유지한다.
- 서하와 메인·지역 NPC 대화 일러스트 21명의 배경을 imagegen으로 다시 분리했다. 도구가 실제 알파 대신 체크무늬를 반환해 순색 키 배경으로 재생성하고 Unity의 제한된 인물 아틀라스 가져오기 과정에서 실제 PNG 알파로 변환한다. 검은 의상과 머리카락은 투명 처리 기준에 사용하지 않는다. 정확한 프롬프트와 생성 위치는 `portrait-prompts.json`에 기록했다.

최종 Windows 빌드 성공: 오류 0, 기존 경고 91. `CitySafetyActionsProbe`의 별도 Windows 실행에서 필수 동작 29개 통과, 실행 오류 0. 실제 물리 충돌, 차량 사고 신고와 추격·정차, 체력 회복, 지상 어그로와 독립적인 자동 중력 포획, 항공기 추락·취소, 소방대 진압·중상자 안전지대 구조 및 구급 신고, PNG 알파를 확인했다. 저장 파일을 기록하지 않으며 평상시 실행에서는 진단 코드가 작동하지 않는다. 검증 결과와 실행 이미지, 빌드 결과를 이 폴더에 보관한다. 전체 캠페인이나 모든 건물의 내부를 전수 플레이하는 검증은 포함하지 않는다.

실행: 현재 게임을 종료하고 프로젝트 루트의 `PLAY.cmd`를 실행한다. 실행 경로는 `Builds/CitySafetyActions/AFTERSIGNAL.exe`다. 사용자 실행 중인 이전 버전은 종료하지 않았다.
