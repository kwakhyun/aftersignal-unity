Cycle 1: 독립 실행을 복구하고 집·무기·마을을 연결했다. 화면에서 NPC 크기와 마지막 계단 충돌이 남았다. Cycle 2: 실제 몸체 크기와 옆 복도를 수정했으며, GPU 반전 검사를 추가해 이동 표시 문제를 확인했다. Cycle 3: 바깥 여는 문, 시설별 의자·서가·병상·콘솔, 밝기·간판 크기·네온·HUD를 정리했다. 각 이전 캡처와 실패 보고는 Artifacts/Residence에 보존했다.

## 아트 규칙과 화면 구성

기준은 **밀도 있는 / 낡은 / 생동하는** 야간 도시. 서하의 은백색 머리·빨간 스카프·어두운 작업복을 유지하고, 밤 거리에는 청색 구조·황동 창·분홍/라임 표지를 제한적으로 쓴다. 집은 나무와 따뜻한 창문광, 의료 시설은 상아색과 낮은 채도의 청록이다. 위험은 붉은색에 번호·괄호·문구를 함께 표시한다.

인물과 접촉 위치를 화면 중앙에서 읽을 수 있도록 정보의 우선순위를 정했다. 코너 HUD, 무기별 원본 포즈, 작은 접촉 효과, 3D 외벽과 원경의 분리를 적용했다. 앞선 표현 원칙은 `../Quality/QUALITY.md`에 기록했다. 실제 플레이 캡처를 기준으로 화면 구성과 가독성을 확인한다.

- 새 액션·깊이 스프라이트: 288×288, PPU 49, 발 (144,16), Point, 개별 PNG. 원본 seo 프레임은 유지. 시뮬레이션 좌표를 픽셀 격자에 고정하지 않는다.
- 인물 셰이더는 깊이 검사와 기록을 유지하며 약한 환경광 반응·개별 접지 그림자를 쓴다. 수목만 시야를 가릴 때 국소 페이드한다. 전 캐릭터를 항상 앞에 그리지 않는다.
- 3D 배경을 통째로 픽셀화하지 않는다. 배경 표면은 저광택과 mipmap, 인물은 Point로 역할을 나눈다.
- VFX는 민트/황동 짧은 궤적과 접촉 섬광, 붉은 위험 표시. 기존 효과 동시 상한과 오디오 14 voice 제한을 유지한다. 전체 화면 점멸로 포즈를 덮지 않는다.
- UGUI, 한국어 폰트, 1600×900 기준 여백. 별도 게임패드 안내를 지원했다고 표시하지 않는다.

콤보 표현은 예비 → 접촉 → 후속 → 복귀 4핵심 포즈를 타이밍 데이터에 맞춰 비균등 유지한다. 판정은 표현 프레임 번호가 아니라 초 단위 활성 구간을 교차 검사한다. 입력 버퍼 140ms. 권총 대시 75ms 간격 3발, Q 80ms 간격 5발. Q 비용 30, 쿨다운 4초. 장전 1,150ms, 약 54%에 탄창 삽입음, 완료 때 탄약 보충·슬라이드음. 공격/명중과 오디오는 같은 사건에서 발생한다. 헛스윙에는 적 명중 반응·명중 히트스톱이 없다. 기존 Time.timeScale 보존형 일시정지와 개별 정지를 유지한다.

## 검증과 실행

`PLAY.cmd` 또는 `Builds/Windows/AFTERSIGNAL.exe`로 실행한다. 에디터는 Unity 6000.4.0f1이며 엔진 업그레이드나 파이프라인 전환은 하지 않았다. 메뉴 `AFTERSIGNAL/Residence/Build playable city`는 해당 6개 씬을 재작성하므로 수동 씬 편집본을 먼저 보관한다. 전체 재생성 도구도 23개 배경·네온 구성을 적용하도록 맞췄다.

1. `Tools/Test-Project.ps1`: EditMode 17 / PlayMode 28 통과. 저장 호환·중복 판정·장전·좌우 방향·저속 연사·문·승강기·첫 퀘스트 완료 플래그를 검사했다.
2. `Tools/Test-Residence.ps1 -Label Iteration5 -Video`: 방→시설→본부→외벽→마을, 오류 0. 본부 외벽 잠금 확인 후 기존 열차 완료 플래그를 테스트용으로 설정하는 fixture만 사용한다. 이동·로프·피해는 일반 입력 경계로 실행한다.
3. `Tools/Test-ReleaseRoutes.ps1`: 최종 릴리스에서 원래 열차, 기존 복원 캠페인, 새 주거 경로를 순서대로 실행한다. 캡처·동영상 없음. QA 실행 종료 시 6개 게임 저장 키를 복원한다.

1.3 릴리스 검증: 열차 3,212프레임 평균 16.667ms / P99 16.670ms / 33ms 초과 0회. 확장 캠페인 23,494프레임 평균 16.692ms / P99 16.702ms / 초과 8회. 주거 경로 8,533프레임 평균 16.771ms / P99 16.673ms / 초과 5회. RTX 4060 Ti, Ryzen 5 7500F, 1600×900, D3D11, vSync 0, Release. 주거 재측정에서도 포커스 상태에서 긴 프레임이 남았으므로 안정적인 60FPS를 전체 합격으로 선언하지 않는다. 15/120FPS 전투 시퀀스와 효과 ON/OFF 검증은 통과했다. 입력 감각에 대한 수동 체험 검증은 이 체크포인트 시점에 미완료이며 1.4 도시 작업으로 이어졌다.

## 신규 에셋 출처와 남은 차이

`Sources/`의 PNG는 이 프로젝트의 기존 서하 이미지를 기준으로 OpenAI 이미지 생성 도구에서 만든 원본 초안이다. 56개 액션·24개 방향 프레임·16개 시민 프레임, 23개 사용 배경, 가구·외벽·수목을 정리해 실제 임포트했다. `Tools/Build-ResidenceArt.py`, `Build-DepthSprites.py`는 배경 제거·셀 분리·공유 배율·피벗 정규화용이다. 스프라이트·오디오 검사 JSON을 동봉한다.

신규 효과음 24개는 직접 작성한 DSP로 생성한 원본 WAV이며 기존 64개와 함께 88개 뱅크를 사용한다. 실제 게임 오디오 출력이 영상에 들어간다. 음량·샘플·클리핑을 수치 검사했으며, 사람이 스피커/헤드폰에서 듣는 주관적 믹싱 검수까지 완료한 것은 아니다. 기존 폰트·Unity 패키지 조건은 `../ASSETS.md`와 동봉 라이선스를 따른다. 유료 에셋 구매는 없다.

남은 가장 큰 차이는 수작업 픽셀 애니메이션이다. 새 깊이 이동은 방향당 4프레임이므로 8~12프레임의 정확한 교차 발디딤과 무기·스카프 후행동작을 추가할 여지가 있다. 시민도 역할 4종·짧은 루프 중심이다. 일부 소품은 단순한 기하 형태이며 23개 맵 전체가 수작업 레벨 아트로 완성된 상태는 아니다. 다음 우선순위는 깊이 걷기와 시민 실루엣 정리, 건물별 상점 파사드·재질 변형, 실제 청취 믹싱, 최소 사양·초광폭·다른 GPU 검증이다. 이를 파티클·Bloom으로 해결한 것으로 보고하지 않는다.

되돌리기는 기존 1.2 ZIP을 별도 폴더에 풀어 실행하는 방식이 가장 확실하다. 현재 파일 위에 덮어쓰지 않는다. 작업 전 Assets/AfterSignal·Settings·ProjectSettings 복사본은 `Artifacts/Residence/Before`에 보존했다. 새 세이브 키 삭제 없이 원래 0~17 구역 값은 유지되며, 구버전으로 실행하기 전 새 18~22 구역에 저장했다면 현재 버전에서 마을로 돌아온 뒤 종료한다.
