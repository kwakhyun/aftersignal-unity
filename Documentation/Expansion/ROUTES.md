# AFTERSIGNAL 1.2 · 확장 노선

Unity의 기존 중앙역 → 객실 → 열차 지붕 캠페인을 보존하고, 애프터라이트에서 세 개의 후속 챕터를 시작하도록 확장했다. 웹 버전의 지역 테마를 참고한 새 Unity 공간이며, 웹 게임 전체 규칙의 일괄 이식은 아니다. 엔진과 URP 버전은 유지한다.

## 마을

애프터라이트는 길이 44m에서 118m로 확장했다. 지상 광장, 5m 높이 산책로, 6m 작업실, 11m 옥상 정원으로 구성된다. 민에게 보급 의뢰를 받고 강변 선착장에서 상자를 회수한다. 윤의 의뢰는 동쪽 승강기와 에스컬레이터로 옥상 안테나를 방문한 뒤 보고한다. 다미의 작업실과 광장 쉼터에서는 체력을 회복한다.

마을의 노아에게 메인 의뢰를 받은 뒤 광장 아래 노선 단말을 사용한다. 각 챕터의 마지막 중계기를 복구하고 출구를 통과하면 마을로 귀환한다. 주민 보상은 한 번만 지급하며 기존 Stage/Memories/Completed 저장 키와 씬 ID 0–3을 보존한다. 추가 진행은 Expansion.Chapters/Accepted/Jobs 키를 사용한다.

| 챕터 | 노선 | 주요 이동 |
| --- | --- | --- |
| 1 · 밤의 열차 | 중앙역 → 객실 → 도시 위의 열차 | 승차, 객실 유리, 객차 사이 로프, 기존 컨덕터 패턴 |
| 2 · 청계의 기억 | 빗속의 거리 → 상가 → 수로 → 화물선 → 연구동 → 수직 기록동 → 중계탑 | 상가 에스컬레이터, 수로 두 번 횡단, 연구동 승강기, 외벽 로프와 고층 유리 |
| 3 · 왕관의 균열 | 전선 위의 하늘 → 용광로 → 왕관 | 옥상 진입, 주조 공장 상층, 송신망 복구 |
| 4 · 기억의 기원 | 도시의 맥박 → 유리 천문대 → 기원 | 끊긴 수로, 천문대 외벽, 기원 서버 상층 |
| 주민 의뢰 | 애프터라이트 ↔ 새벽의 선착장 | 보급 상자와 지역 기록 회수 |

총 18개 씬: 기존 전투 씬 3개, 확장 마을 1개, 새 캠페인 구역 13개, 선착장 1개. 후속 구역에는 기존 적 3종을 재배치했다. 일반 적의 체력과 무기 피해 규칙, 기존 컨덕터의 축전기/코어 규칙을 바꾸지 않았다. 후속 챕터에 새로운 보스 종류를 추가한 것은 아니다.

## 편집과 재현

- `AFTERSIGNAL / Expansion / Build town and new districts`: 마을 및 추가 구역을 생성한다. 생성 전에 수동 씬 편집본을 별도로 보관한다.
- `AFTERSIGNAL / Quality / Bake geometry batches`: 원본 오브젝트와 충돌체를 보존하고 재질·공간 단위로 표시 메시를 합친다. 승강기, 유리, 셔터, 포탈, 앵커는 합치지 않는다. 움직이는 도시와 열차의 배치는 해당 이동 루트 아래에 둔다.
- 배치 후 원본 구조를 수정했다면 다시 굽는다. `SceneBatchManifest`의 sources를 켜고 generated를 끄면 합치기 전 표시를 확인할 수 있다.
- `-expansion-smoke -quality-output <폴더>`: 일반 입력 경계를 사용하는 확장 경로 QA. 첫 마을을 시작 상태로 사용하는 별도 테스트이며 기존 열차 챕터는 `-aftersignal-smoke`로 검증한다. 두 플래그를 동시에 사용하지 않는다.
- `Tools/Test-Project.ps1`: 전투 회귀, 새 승강기와 에스컬레이터, 의뢰 중복 보상, 충돌체 보존 검사.

## 보존과 한계

이번 작업 전 코드·씬·설정은 `Artifacts/Expansion/Before`에 보존했다. 배포된 1.1 ZIP도 덮어쓰지 않는다. 원래 씬의 `.meta`와 GUID를 보존했으며 새 콘텐츠는 새로운 파일을 추가한다.

신규 구조물은 프로젝트의 기존 재질과 새 팔레트를 사용하는 자체 제작 Unity 메시다. 외부 게임의 모델·텍스처·캐릭터·음원을 복제하지 않는다. 기존 자체 제작 스프라이트, 오디오, Noto Sans KR의 출처는 `Documentation/ASSETS.md`와 이전 `Documentation/Quality` 기록을 따른다. 반복형 모듈 외관과 일부 기존 무기 애니메이션에는 추가 아트 제작 여지가 있다. 실제 경로·성능 합격 여부는 이 문서의 설계 설명과 별개로 실행 결과를 확인해야 한다.
