# 그래픽·월드 품질 개선

현재 게임은 넓은 기능을 가진 절차 생성 프로토타입이다. GTA V, Cyberpunk 2077, 이환과 같은 완성도를 달성한 상태가 아니다. 큰 격차는 반복적인 거리 구성, 단순한 재질·조명, 캐릭터와 배경의 서로 다른 제작 수준, 로컬 회피 위주의 보행자 이동, 모든 도시를 한 번에 만드는 월드 구조에 있다.

이번 작업은 기존 변경사항을 `0968b341`로 main에 커밋·푸시한 다음 진행했다. 기존에 설치되어 있던 Blender 4.5.3을 실제 모델 제작·감량·렌더 검수에 사용했다. 엔진만 교체하거나 프로그램을 추가로 설치하는 것으로 품질 차이가 해결된다고 가정하지 않았다.

## 적용한 개선

- 주요 도로·보도·콘크리트·금속에 실제 표면에서 제작된 2K 재질 4종, 12개 텍스처를 적용했다. 표면 방향에 맞는 법선, 거칠기, 주변광 차폐, 조명·반사 반응을 추가했다.
- 창틀·블라인드·실내 깊이 표현과 점등 여부가 다른 창문을 구현했다. 기존 도심의 흰색 창문 과다 발광을 줄이고 유리 파손 기능과 연결했다.
- 신규 도시 구역의 타워에 여섯 가지 형태, 저층 상업부, 캐노피, 테라스, 연결 다리, 차양, 외부 구조와 옥상 설비를 적용했다. 기존 시내 건물 전체를 개별 수작업 에셋으로 교체한 것은 아니다.
- Blender로 모서리와 재질을 다듬은 거리 소품 7종을 제작했다. 안내 지도, 교통 안내, 차량 충전, 벤치 휴식을 연결했고 주변에 최대 48개 지점만 생성한다.
- 조경에 실사 기반 나무와 거리별 메시 3단계를 적용했다. 줄기·가지·잎을 별도로 감량해 최초 감량에서 발생한 형태 손상을 수정했다.
- 신설 문화·공공시설 실내에는 천장 등기구와 플레이어가 있는 층 주변의 조명을 적용했다. 지면과 겹치던 로비 바닥을 3cm 높였다.
- 보행자는 단단한 장애물을 우회하고 다른 시민과 간격을 벌리며 바닥이 없는 지점에서 멈춘다. 코너에서 방향을 계속 바꾸며 맴돌던 문제를 수정했다. 기존 이동 목적지와 생활 일정은 유지한다.
- 주변 상호작용 후보를 캐싱해 매 프레임 전체 NPC 컴포넌트를 조회하는 비용을 줄였다. 이동·비활성화·도시 간 이동 후에도 대상을 갱신한다.
- 그림자 거리·해상도, 계단 현상 완화, 근거리 반사, 낮·밤 노출과 구름을 보완했다. 시야를 막는 건물의 잔상을 줄였다.

## 실행과 설정

`PLAY.cmd`는 갱신된 `Builds/Fidelity/AFTERSIGNAL.exe`를 실행한다. ESC 메뉴 맨 아래 **그래픽** 버튼에서 **성능 / 고품질 / 최고 품질**을 전환한다. 기본값은 고품질이다.

Unity의 `AFTERSIGNAL > Quality > Apply physical city materials and rendering` 메뉴는 재질 임포트 설정과 식생 LOD 프리팹, PC 렌더링 설정을 재적용한다. 제작 원본을 다시 만들려면 `Tools/Fidelity/`의 다운로드·Blender 생성·패키징 스크립트를 사용한다. 제3자 에셋의 출처와 해시는 아래 기록에 있다.

## 검증 기록

2026-09-08 정정: 당시 `SingleCameraRequest` 촬영은 URP volume 갱신을 건너뛰어 실제 게임의 후처리 경로와 달라질 수 있었다. 아래 시간은 당시 경로의 기록이며 후처리를 포함한 최종 성능 결과로 해석하지 않는다. 수정된 촬영 방식과 지면·돔 복구는 [WorldRecovery](../WorldRecovery/README.md)를 참고한다.

실제 Windows 플레이어에서 낮·밤 도심, 경기장, 노바 구역, 수중 도시, 실내, 정원, 거리 소품, 설정 화면을 확인했다. 출입·계단·승강기 검사와 새 이동·상호작용·유리 파손 검사를 수행했다. 상세 통과 항목, 빌드 결과, 동일 카메라 비교 시간은 [validation.json](validation.json)에 기록한다.

최종 필수 검사 **70개 통과**, 실행 오류 **0개**, Windows 빌드 성공(오류 0개, 경고 47개). 검수 원본: [야간 이전](Review/night-before.png) / [야간 적용 후](Review/night-after.png), [실내 이전](Review/interior-before.png) / [실내 적용 후](Review/interior-after.png), [정원](Review/garden-after.png), [거리 소품](Review/street-after.png).

백그라운드 Windows 창은 일반 화면 렌더링을 생략할 수 있으므로, 비교 측정은 1600×900 프레임을 명시적으로 렌더링하고 GPU 읽기 완료를 기다린다. 측정값에는 동기화 비용과 실행 시점의 변동이 포함되어 있으며 일반 플레이 FPS 보증값이 아니다. 장시간 플레이나 여러 사양에 대한 전체 QA는 수행하지 않았다.

RTX 4060 Ti의 이 비교 실행에서 평균 프레임 시간은 도심 낮 31.93→33.21ms, 밤 28.25→36.12ms, 경기장 11.80→16.54ms, 노바 13.91→17.26ms, 수중 도시 28.36→34.65ms, 실내 27.55→31.55ms였다. 이번 표현 개선은 비용이 증가한 변경이며 성능 향상으로 보고하지 않는다. ESC의 성능 프리셋은 반사 프로브·그림자·렌더 해상도 비용을 낮춘다. 향후 목표는 이러한 품질을 유지하면서 월드와 NPC 처리 비용을 줄이는 것이다.

## 같은 수준에 접근하기 위한 후속 제작 기준

1. 도시 전체를 계속 넓히기보다 약 400m 규모의 대표 구역에서 건축·도로·상점 실내·NPC·임무를 하나의 완성된 플레이 경험으로 제작한다. 그 구역의 자산 규격을 다른 지역으로 확장한다.
2. 주인공과 NPC의 아트 스타일을 결정하고, 그 기준을 충족하는 모델·리깅·모션 제작 공정을 확보한다. 현재 2D 캐릭터를 낮은 품질의 3D 시안으로 대체하지 않는다. 실제 체형, 실루엣, 발 접지와 동작 전환을 검수해야 한다.
3. 월드를 셀과 실내 장면으로 분리하고 비동기 로딩, 거리별 통합 메시, 메모리 예산과 경로 데이터를 함께 운영한다. 이번 거리 소품 스트리밍은 그 전체 시스템을 대신하지 않는다.
4. 시설별 경로 탐색, 상태 전환, 군중·차량·전투 규칙을 실제 플레이 시나리오로 검증한다. AI 대사 생성과 캐릭터 이동 제어는 독립적으로 동작해야 한다.
5. 대표 구역에서 CPU/GPU별 병목과 목표 프레임 시간을 먼저 달성한 다음 밀도와 시각 효과를 늘린다. 컷신·연기·음향 믹싱·장시간 QA에는 별도의 콘텐츠 제작과 반복 검수가 필요하다.

구체적인 코드 조사와 Unity·CD Projekt Red·건축가의 1차 참고 자료는 [QUALITY-DIRECTION.md](QUALITY-DIRECTION.md), 재질 출처는 [material-provenance.json](material-provenance.json), 식생 출처는 [botanical-provenance.json](botanical-provenance.json)에 있다.
