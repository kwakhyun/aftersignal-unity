# 서하와 도시 생활 업데이트

## 서하 이미지
첨부 일러스트를 기준으로 `image_gen.imagegen`으로 새 스프라이트 10장, 80프레임을 제작했다.
은보라색 묶은 머리, 검은 비대칭 재킷, 검은 바지와 부츠를 공통 기준으로 사용한다.
- MoveFront / MoveBack / MoveLeft / MoveRight: 각 4프레임 걷기 + 4프레임 달리기.
- Base: 방향별 대기, 점프·공중·착지.
- Context: 앞뒤 대시, 피격, 운전.
- Katana / Greatsword / Pistol: 무기별 공격·방어·기술·장전.
- Rope: 로프 잡기·매달림·스윙·끌어올리기·놓기.
생성 프롬프트는 `Art/seo-illustrated-prompts.json`에 보관한다. 원본 이미지의 흰색/체크 무늬 배경은 Unity 임포터에서 투명 처리하며 소스 PNG를 보존한다.
상반신 일러스트 원본은 `Resources/Art/Portraits/Seo.png`, 신규 도트 이미지는 `Resources/Art/SeoIllustrated`에 저장한다.

## 조작과 기능
- WASD 기본 이동은 걷기. 같은 방향 키를 0.28초 안에 두 번 누르면 달리며, 키를 놓으면 걷기로 돌아온다.
- 마우스 가운데 버튼 드래그 시점 회전, HOME 초기화는 유지.
- 애프터라이트 허브 동쪽 도시 입구에 접근하면 도보·차량 모두 자동 진입한다.
- AI 대화창은 화면 하단. 좌측 서하 일러스트, 스크롤 가능한 본문, 답변 생성 상태와 경과 시간을 표시한다.
- 차량 유리는 투명하고 운전자·동승객이 보인다. 운전 중에는 서하 전용 운전 그림을 표시한다.
- 101~105번 버스가 기존 25개 정류장을 운행한다. 정류장에서 E로 30 C를 내고 탑승, 탑승 중 E로 하차벨, 정차 후 하차한다. 정차 시 승객이 내리고 새 승객이 탄다.
- 식당·카페 직원의 서비스 메뉴에서 아르바이트 시작. 손님 응대 → 주문에 맞는 음식/음료 선택 → 타이밍 맞추기 → 해당 테이블 서빙. 주문마다 기본급과 품질에 따른 팁 지급. 5명 응대 후 근무 완료.
- 아파트 주민 안내에서 호실을 선택하거나 북쪽 주택가 문에서 E로 방문한다. 나무 마루, 주방, 거실, 침실과 가구는 3D로 구성한다.
- 주소가 있는 주민 24명은 시간표에 따라 출근·근무·카페 교류·귀가·휴식한다. 낮에는 직장 내부, 밤에는 집 내부에서 만날 수 있다. 일과와 주소를 기존 실시간 AI 대화의 배경으로 전달한다. 이동/일과 계획은 게임 내 시간표로 실행한다.

## 검증
사용자의 요청대로 기능별 필수 연결만 확인한다.
`-city-living-smoke`는 저장 파일을 보호한 채 입구, 이미지, 버스 요금과 승하차, 급여, 방문과 시간대별 주민 출현을 확인하고 UI/아트 화면을 캡처한다.
빌드·실행 결과는 `Artifacts/CityLiving`에 기록한다.
