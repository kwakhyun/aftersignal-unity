# 갱단 전용 스프라이트

- 적철단: 붉은 재킷, 목의 반다나와 검은 카고 바지.
- 바이올렛 크루: 보라색 후드와 검은 조끼, 보라색 운동화.
- 녹슨 송곳니: 올리브색 항공 점퍼, 뒤로 쓴 모자와 갈색 부츠.

`Resources/Art/Gangs`의 원본 PNG 3장을 `image_gen.imagegen`으로 제작했다. 생성 프롬프트는 `gang-prompts.json`에 보관한다. 기존 적 스프라이트와 전체 색상 틴트를 사용하지 않는다.

각 시트는 4열 × 2행, 왼쪽 위부터 대기 / 달리기 A / 달리기 B / 조준 / 사격 / 피격 / 무릎 꿇기 / 쓰러짐의 8프레임이다. 경찰과 공유하는 `PoliceSpriteImporter`가 원본을 보존하면서 흰 배경과 가장자리의 흰 잔상을 투명 처리한다. 분리된 섬광까지 해당 프레임에 포함하며, 발 기준 피벗과 2.1m 대기 신장으로 맞춘다. 쓰러짐은 전용 수평 이미지로 재생한다.

`GangSpriteCatalog`가 소속별 이미지를 지정하고 `GangMember`가 실제 도시 교전에서 재생한다. 총구는 조준 이미지의 끝부분에 연결하며, 화면에서 상대가 있는 방향으로 좌우 반전한다.

필수 확인: Windows 빌드의 `-gang-camera-smoke`로 24프레임과 카메라 회전·충돌을 확인하고, `-gang-war-smoke`로 실제 교전을 확인한다. 상세 결과는 무시되는 `Artifacts/GangCamera`에 기록한다.
