# 3인칭 조작·사건 일지 업데이트

## 실행과 조작

`PLAY.cmd`로 갱신된 Windows 빌드를 실행합니다.

| 입력 | 기능 |
| --- | --- |
| 마우스 이동 | 버튼을 누르지 않고 상하좌우 시점 회전 |
| 화면 중앙 조준점 | 공격·로프 목표 선택 기준 |
| 마우스 휠 | 시점 확대·축소 |
| 1 / 2 / 3 | 카타나 / 대검 / 권총 |
| WASD | 기본 달리기 (걷기 구분과 두 번 누르기 제거) |
| 왼쪽 / 오른쪽 마우스 | 공격 / 로프 |
| J | 사건 일지 열기·닫기 |
| E | 대화·증거 조사·전달·시설 이용 |
| HOME | 기본 3인칭 거리와 각도 복귀 |
| ESC | 대화 닫기·일시정지 |

메뉴·대화·지도에서는 커서 잠금이 풀리고 휠로 UI를 스크롤할 수 있습니다. 카메라는 어깨 옆을 기준으로 바라보며 벽과 충돌하면 거리를 줄입니다. 휠로 무기가 바뀌지 않습니다.

## 일러스트와 투명 깨짐

- 대화창에 새 서하 상반신 일러스트를 적용했습니다. 원본 캐릭터의 얼굴·은보라색 머리·비대칭 전술복을 유지하면서 얼굴이 더 잘 보이게 구성했습니다.
- 새 일러스트는 어두운 배경을 포함한 불투명 이미지입니다. 밝은 머리카락과 피부를 배경으로 오인해 지우지 않습니다.
- 서하의 기존 전투·대시·로프 시트는 이미지 내부의 밝은 픽셀까지 제거하던 처리를 수정했습니다. 이미지 외곽과 이어진 배경만 제거합니다.
- 최종 이미지: `Assets/AfterSignal/Resources/Art/Portraits/SeoDialogue.png`.
- 내장 `image_gen` 도구로 제작. 원본·프롬프트: [Art/seo-dialogue-prompt.json](Art/seo-dialogue-prompt.json).

## 메인 24개·서브 18개

새 이야기는 '지워진 열일곱 분'이라는 기억 유출 사건을 다룹니다. 각 의뢰는 대화·조사·전달·전투·선택지 중 세 단계로 구성되며 총 126개의 목표 단계가 있습니다. J 일지에서 의뢰를 선택하면 선행 조건, 현재 단계, 목적지, 보상을 확인하고 추적할 수 있습니다.

| 메인 이야기 | 이어지는 단서 |
| --- | --- |
| 1막 · 지워진 아침 | 우편함 → 카페 주문표 → 진료 기록 → 출석부 → 삭제 승인 |
| 2막 · 검은 배송장 | 사라진 약 → 물류 운송장 → 블랙박스 → 가짜 순찰차 |
| 3막 · 밤의 증언 | 바의 통화 → 유치장 수첩 → 위조 무전기 → 동결 계좌 |
| 4막 · 두 개의 도시 | 광고 중계망 → 가짜 동의서 → 본부의 책임 → 기억의 소유권 |
| 5막 · 마지막 운행 | 미등록 승객 → 이동 서버 → 대체 구호 배송 → 전송망 봉쇄 |
| 6막 · 애프터시그널 | 돌아온 기억 → 새 명부 → 후속 돌봄 → 시민이 관리하는 기록 |

주민 의뢰는 이웃 은서, 간호사 다은, 교사 수연, 정비사 민재, 순경 지훈, 바텐더 라온의 여섯 이야기로 묶입니다. 각 세 편이 연결되며 메인 사건에서 얻은 정보가 주민의 생활 문제와 이어집니다.

- 조사 단말은 근처에서 3초 동안 기록을 복원합니다. 멀어지면 중단됩니다.
- 증거 방어 단계는 갱단을 제압해야 진행됩니다.
- 선택지는 공개와 공동 감독, 당사자 동의와 보호 우선의 원칙을 저장합니다. 누적 선택에 따라 마지막 보고서와 결말이 달라집니다.
- 보상은 의뢰마다 한 번 지급됩니다. 진행·수락 상태·선택·추적 의뢰는 저장됩니다.
- 기존 열차·도시 복원·외벽 기록 임무는 본부의 별도 단말에서 계속 이용할 수 있습니다.

시나리오 데이터: `Assets/AfterSignal/Resources/Story/CityChronicle.json`.
진행 및 목표 생성: `CityChronicle.cs`. 일지와 선택 대화: `CityLife.Story.cs`.

## 시민의 대화

길거리 시민들은 가까운 이웃과 잠깐 멈춰 마주 보고 안부를 나눕니다. 서하 근처의 시민이 먼저 말을 걸기도 합니다. 이동을 강제로 멈추거나 대화창을 자동으로 열지 않으며, 가까이서 E를 누르면 기존 NPC 대화 기능으로 응답합니다.

피격 반응은 노인·학생·의료진·환자·교사·경찰·노동자·바텐더 등 역할에 맞춰 달라집니다. 예를 들어 노인은 '에구구', 의료진은 환자를 보호하는 말, 교사는 학생에게 피하라는 말을 합니다. 피격 대사가 일반 공포 말풍선에 바로 덮이지 않게 했습니다.

시민의 짧은 상호작용과 고정 사건 시나리오는 로컬에서 실행됩니다. 기존 OpenAI NPC 대화 연결은 사용자가 NPC와 대화할 때 이용합니다.

## 필수 확인 범위
