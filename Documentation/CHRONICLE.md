# 3인칭 조작·사건 일지 업데이트

## 실행과 조작

`PLAY.cmd`로 갱신된 Windows 빌드를 실행합니다.

| 입력 | 기능 |
| --- | --- |
| 마우스 이동 | 버튼을 누르지 않고 상하좌우 시점 회전 |
| 화면 중앙 조준점 | 공격·로프 목표 선택 기준 |
| 마우스 휠 | 시점 확대·축소 |
| 1 / 2 / 3 | 카타나 / 대검 / 권총 |
| WASD | 기본 달리기 (걷기 구분과 두 번 누르기 제거) |
| 왼쪽 / 오른쪽 마우스 | 공격 / 로프 |
| J | 사건 일지 열기·닫기 |
| E | 대화·증거 조사·전달·시설 이용 |
| HOME | 기본 3인칭 거리와 각도 복귀 |
| ESC | 대화 닫기·일시정지 |

메뉴·대화·지도에서는 커서 잠금이 풀리고 휠로 UI를 스크롤할 수 있습니다. 카메라는 어깨 옆을 기준으로 바라보며 벽과 충돌하면 거리를 줄입니다. 휠로 무기가 바뀌지 않습니다.

## 일러스트와 투명 깨짐

- 대화창에 새 서하 상반신 일러스트를 적용했습니다. 원본 캐릭터의 얼굴·은보라색 머리·비대칭 전술복을 유지하면서 얼굴이 더 잘 보이게 구성했습니다.
- 새 일러스트는 어두운 배경을 포함한 불투명 이미지입니다. 밝은 머리카락과 피부를 배경으로 오인해 지우지 않습니다.
- 서하의 기존 전투·대시·로프 시트는 이미지 내부의 밝은 픽셀까지 제거하던 처리를 수정했습니다. 이미지 외곽과 이어진 배경만 제거합니다.
- 최종 이미지: `Assets/AfterSignal/Resources/Art/Portraits/SeoDialogue.png`.
- 내장 `image_gen` 도구로 제작. 원본·프롬프트: [Art/seo-dialogue-prompt.json](Art/seo-dialogue-prompt.json).

### 추적과 개방

- 본편(최종장까지 `after`로 이어지는 의뢰)은 완료하면 다음 의뢰를 자동으로 추적합니다.
- 같은 의뢰 뒤에 열리는 갈래(중앙역 탈환 뒤의 도시전)와 새로 조건을 채운 주민 의뢰는 자동 추적하지 않고 완료 알림에 "새 의뢰 개방 · …"으로 알립니다. J 일지에서 추적할 수 있습니다.
- 갈래 의뢰를 끝까지 마치면 아직 끝나지 않은 가장 앞선 본편 의뢰로 추적이 돌아갑니다.

### 결정과 결말

본편에는 결정 단계가 다섯 개 있습니다. 선택지 문구는 의뢰마다 다르며, A는 공개 쪽(저장값 1), B는 당사자 동의·보호 쪽(저장값 2)입니다.

| 의뢰 | 결정 | A (공개) | B (동의·보호) |
| --- | --- | --- | --- |
| 강철 아래의 증언 | 수송 명단 처리 결정 | 명단 공개 · 가족 찾기 방송 | 가족에게만 비공개 연락 |
| 폭풍 속 기록금고 | 승인 문서 처리 결정 | 승인 문서 즉시 전면 공개 | 증인 보호 · 독립 조사단 제출 |
| 침묵을 깨는 방송 | 증언 방송 방식 결정 | 실명 생방송 · 전원 공개 | 익명 처리 · 동의한 증언만 |
| 아틀라스의 진실 | 기억 원본 처리 결정 | 원본 공개 열람 · 시민 검증 | 당사자 반환 · 미동의 기록 봉인 |
| 꺼지지 않는 신호 | 복원 신호 송출 방식 결정 | 도시 전역 일괄 송출 | 동의한 시민에게 개별 송출 |

- 결말은 `"finale": true`인 의뢰(우리의 내일)의 마지막 단계 대화에서 공개됩니다. A 선택 수가 B 선택 수보다 많으면 공개 기록 결말(`endingA`), 같거나 적으면 동의의 기록 결말(`endingB`)입니다. 완료한 주민 의뢰 수도 함께 표시됩니다.
- 현재 결정 단계가 있는 의뢰의 선택만 집계합니다. 결정 단계가 추가되기 전에 해당 의뢰를 마친 저장 파일은 그 의뢰의 선택이 비어 있으므로 동점이면 동의의 기록 결말로 정해집니다.
- J 일지 첫 화면에 결정 집계(공개 / 동의·보호)가, 의뢰 상세의 "결정:" 줄에 그 의뢰에서 고른 선택지 문구가 표시됩니다.

### 작전 전투

- 시작 조건: 도보 상태이고 수배 단계가 0일 때 작전 지점 34 m 안에 들어서면 전투가 시작됩니다. 차량 탑승 중이거나 경찰 추적 중이면 알림만 표시하고 시작하지 않습니다.
- 방어: 지정 구역(22 m) 안에 머무는 시간만 집계합니다. 지점 26 m 안의 적 한 명마다 방어선이 초당 0.25%(최대 2.5%) 깎이고, 적이 남아 있는데 구역을 벗어나면 초당 1.5%가 더 깎입니다. 0%가 되면 실패합니다.
- 탈출: 단계마다 제한 시간(`timeLimit`)이 있습니다. 추격대를 모두 격파하면 5초 뒤 후방에서 추격조가 따라붙으며, 이들은 처치하지 않아도 됩니다. 시간 안에 청록색 지점에 닿지 못하면 실패합니다.
- 구출: 구조 대상이 쓰러지면 실패합니다.
- 실패하면 무전과 알림이 표시되고 해당 단계를 처음부터 다시 시작합니다. 저장된 단계 번호는 바뀌지 않습니다.
- 난이도: 일반 적 체력은 `95 + 의뢰 순번×3 + 단계×12`입니다(순번은 `after` 연결 깊이, 첫 의뢰 0 · 마지막 의뢰 29). 적 수는 데이터의 `enemyCount`(3~12)를 그대로 쓰고, 본편은 막이 오를수록 4명에서 8명, 2~3차 공격으로 늘어납니다. 거신 체력은 `4800 + 순번×100`, 소거 증폭기는 `180 + 순번×4`입니다. 단계의 `enemyHealth`를 지정하면 체력 공식을 대신합니다(도시전 130·145·160).

## 시민의 대화

길거리 시민들은 가까운 이웃과 잠깐 멈춰 마주 보고 안부를 나눕니다. 서하 근처의 시민이 먼저 말을 걸기도 합니다. 이동을 강제로 멈추거나 대화창을 자동으로 열지 않으며, 가까이서 E를 누르면 기존 NPC 대화 기능으로 응답합니다.

피격 반응은 노인·학생·의료진·환자·교사·경찰·노동자·바텐더 등 역할에 맞춰 달라집니다. 예를 들어 노인은 '에구구', 의료진은 환자를 보호하는 말, 교사는 학생에게 피하라는 말을 합니다. 피격 대사가 일반 공포 말풍선에 바로 덮이지 않게 했습니다.

시민의 짧은 상호작용과 고정 사건 시나리오는 로컬에서 실행됩니다. 기존 OpenAI NPC 대화 연결은 사용자가 NPC와 대화할 때 이용합니다.

## 필수 확인 범위

Windows 빌드와 `-chronicle-smoke` 실행 점검을 사용했습니다. 조작, 대표 의뢰의 대화→조사→전달, 보상 중복 방지, 선택 저장, 일지, 시민 대화·피격 반응을 확인합니다. 모든 장편 의뢰를 처음부터 끝까지 수동 플레이한 검증은 아닙니다.
