실행은 루트 `PLAY.cmd`, 플레이어는 `Builds/RegionalExpansion/AFTERSIGNAL.exe`다. 기존 저장과 차량 내구도·범죄 대응 작업을 유지한다.

## 차량과 조작

- 신규 3D 모델 10종: Vela R·Rosa M·Chimera C 슈퍼카, Metro Sedan·Civic Hatch·Trail SUV·Estate Tourer 일반차, Apex RR·Nomad GS·Classic Twin 바이크.
- 실차의 특징을 참고한 게임 고유 차체다. 앞뒤 범퍼·휠하우스·독립 회전 바퀴·브레이크·유리·필러·좌석·배기구를 모델링했다. 원본 `.blend`와 FBX가 포함된다.
- 차종별 모델이 교통 차량과 주차 차량에 분산되고 소유 차량의 디자인 번호도 저장된다. 스포츠카는 낮은 2인승 캐빈을 사용한다.
- 바퀴로 달리는 차량·버스·트럭·바이크는 속도를 낸 상태에서 **SPACE + A/D**로 드리프트한다. 관성에 따라 차체 방향과 진행 방향이 달라지며 타이어 자국과 연기가 생긴다. 키를 놓으면 접지력을 회복한다. 탱크와 항공·수상 탈것은 기존 전용 물리를 사용한다.
- 기존 **SHIFT 가속**, **B 경적**, **C 탑승 시점**, **좌클릭 탑승 사격**을 유지한다.

## 새벽 저지대

애프터라이트 북쪽 외곽의 넓은 저소득 주거 지구. 가구가 배치된 주택·증축층 534개와 빨랫줄, 급수 탱크, 전선, 노점, 고물·부품 시장을 배치했다. 내부에는 침대·주방·식탁·TV가 있다.

기존 Haven 장면의 건물·주민·집/학교/병원/본부 출입구를 `HavenQuarter.prefab`으로 보존해 저지대 서남쪽에 통합했다. 이전 마을로 향하던 이동과 저장 진입도 같은 도시의 고향 구역으로 연결한다. 서하의 집 내부는 기존 장면과 금고를 사용한다.

180명의 지역 주민은 18종 직업과 기존 통일된 시민 외형을 사용한다. 이웃 친밀도는 80에서 시작하고 대화로 상승, 폭력으로 하락하며 AI 대화 배경에도 반영된다. 밤에는 갱단의 기존 강탈·도난 행동이 발생하고 지역 순찰대 12명을 운영한다.

시장 공동 단말 **E**: 저가 공동식사, 암시장 무기 거래, 4분 제한 비공식 부품 운송(450 C), 집 이동. 암시장 거래와 인계도 기존 목격·신고 규칙을 사용한다. 운송 목적지는 지도 경로에 표시한다.

## 도시별 시설

기존 28개 주요 시설에 지역/시설 항목 32개를 더해 60개로 확장했다. 신규 항목의 주민 배치 정원은 총 1,560명이며 접근한 구역의 인원만 활성화한다.

- **노바**: 방위기지, 교도소, 시청, 경찰서, 소방서, 은행, 식당, 카페, 학교, 도서관, 병원, 광장. 유리 의회관·소방 출동 캐노피·목재 도서관 구조 등 시설별 실루엣을 달리했다. 기지에는 조종 가능한 전차 6대, 전투기와 전투헬기를 둔다.
- **네레이드**: 기존 행정 시설을 전용 시청으로 개편하고 의료원을 개선했다. 별도의 기밀 생활권에 경찰·소방·은행·식당·카페·학교·도서관·광장을 추가했다. 압력 쉘, 공기 순환 탱크, 산호형 지붕과 시설별 장비를 갖추고 기밀 도로로 연결한다.
- **에레보스**: 특수작전기지, 잠식 연구기관, 격리 실험실과 파괴된 군부대·교도소·시청. 중앙에 직경 420m, 깊이 약 140m의 실제 지형 붕괴구를 구현했다. 도로는 가장자리를 우회하고 해수면은 구멍을 덮지 않는다. 근처에서 잠식체와 특수부대의 양방향 교전이 반복된다.

업무 시설에는 직원·이용객, 다층 바닥, 계단, 승강기, 역할별 집기와 화장실을 배치했다. 은행 입출금·시설 현금함, 식사·음료·아르바이트, 학교 공개 수업, 도서관 자료 열람, 소방 응급 교육을 이용할 수 있다. 경찰서 경비는 범죄에 대응한다. 죄수는 수용동 안에 머물고 특수부대·군인·죄수 외형은 일반 시민 보정에 덮어씌워지지 않는다.

## 해협 섬마을

솔바람 어촌, 러스티 조선섬, 오키드 생태섬, 유리등대 해상마을의 네 종류. 굴곡진 모래 해안·암석·부두와 주택 내부를 만들고, 마을별로 어구·크레인·재배 온실·등대를 추가했다. 어부·선장·조선공·해양 재배사·상인·등대 관리인이 생활한다.

## 구현과 검증 범위

건축물은 Unity 런타임의 파라미터 기반 3D 메시이며, 차량은 Blender 제작 에셋이다. 실차 정밀 스캔이나 AAA급 개별 수작업 에셋으로 소개하지 않는다. 주민 일상·전투는 로컬 게임 로직이고, 대화는 기존 AI 연결과 시설별 실제 사용 안내를 사용한다.

`RegionalExpansionSmoke`는 새 구역의 지면·각 층·지형 구멍·우회 도로, 모델 로드와 드리프트, 고향 연결·친밀도·순찰·메뉴, 교전과 섬 항로를 실행 확인하고 대표 화면을 저장한다. 최종 Windows 빌드 오류 0건, 필수 실행 확인 116항목 통과(실행 오류 0건). 최종 결과는 이 폴더의 `validation.json`, 화면은 `Artifacts/RegionalExpansion/Final`에 있다. 참고 출처는 `REFERENCES.md`.
