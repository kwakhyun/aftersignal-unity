# Implementation references

Retrieved 2026-09-09. No external meshes, textures or third-party effect packages were copied into this update.

- [Unity — Particle lights and trails](https://docs.unity3d.com/6000.0/Documentation/Manual/particle-lights-trails.html): temporary light limits and fragment trails. The implementation caps effects and uses shadow-free transient lights.
- [SideFX — Real-Time FX with Unreal](https://www.sidefx.com/tutorials/real-time-fx-with-houdini-unreal-engine-5/): reference for layered muzzle flashes, explosions and camera response. Effects here are authored directly for Unity; the Houdini/Unreal course files are not shipped.
- [Unity — Cinemachine Impulse](https://docs.unity3d.com/Packages/com.unity.cinemachine@3.1/manual/CinemachineImpulse.html): impulse-source/listener separation and spatial falloff. The existing CameraRig is extended; Cinemachine was not installed.
- [Unity — AudioSource](https://docs.unity3d.com/6000.0/Documentation/Manual/class-AudioSource.html): audio distance and voice mixing concepts. The game retains its existing master/SFX controls and recorded firearm sources.

Audio source provenance for the existing firearm recordings remains in `Documentation/Audio`; derived gunshot tails are generated by `Tools/WorldExpansion/create_combat_detail_audio.py`. Original impact/pressure layers use a fixed random seed for repeatable builds.
