# Nova Strait / 노바 해협 확장

기존 작업은 `dbc0255c`로 main에 커밋·푸시했다. 이 문서는 그 이후의 탈것·해상 도시 확장 내용을 설명한다.
이 문서에 해당하는 추가 구현은 로컬 작업 트리에 있으며, 아직 별도 커밋·푸시하지 않았다.

## 조작

- 모든 탈것: `C` 조종석 1인칭/외부 3인칭 전환, 마우스 둘러보기, 휠 외부 시점 거리. 운전석에 계기판·핸들 또는 조종간을 표시한다.
- 전차: W/S 전후진, A/D 제자리 궤도 선회, 마우스 독립 포탑, 좌클릭 120 mm 주포, 우클릭 기관총. 주포 32발, 발사 간격 2.6초. 가까운 군용 탈것은 정비소·군부대 서비스에서 200 C에 탄약 재보급.
- 전투헬기/전투기: W/S 추력, A/D 선회, SPACE 상승, CTRL 하강, SHIFT 가속, 좌클릭 기관포, 우클릭 미사일. 조준한 차량을 0.85초 추적하면 유도 발사. 8발 장착, 예비 24발, R 재장전 4.5초.
- 수영: WASD, SHIFT 빠르게, CTRL 잠수, SPACE 상승. 수면에서 SPACE와 이동을 유지하면 비어 있는 부두·해변 턱에 올라간다. 호흡 90초, 수면에서 회복. 산소 소진 시 피해를 받는다.

## 해협과 도시

애프터라이트 여객터미널의 정기 여객선에서 G로 승객석에 타면 노바로 이동한다. 두 항구에서 40초 정박하며 F로 내릴 수 있다. 직접 배나 항공기를 조종해 바다를 건너도 된다. 노바 부두에도 조종 가능한 배, 바이크, 스포츠카가 있다.

노바는 네 개의 섬과 중앙 운하, 11개 도로 노선, 차량용 교량, 보행교, 고가 철도, 수로시장, 해양연구소, 기업 기록금고, 시민의회, 공항, 조수 발전소로 구성된다. 기존 도시에 125동을 추가했고, 확장 전체에 538동의 건물과 31동의 직접 진입 가능한 다층 건물을 제작했다. 간판·창호·차양·발코니·설비·지붕 윤곽을 달리했다. 모든 외관 건물에 내부를 만든 것은 아니다.

시설의 콘솔과 현장 업무는 기존 재화·진료·식당·상점·은행·정비·군수 시스템을 사용한다. 고가 열차는 역에서 대기하고 운행하는 배경 교통이다. 탑승 가능한 대중교통은 버스·여객선·여객기이다.

새 주민 24종을 전후좌우로 제작했다. 해양 기술자, 잠수부, 선박 관제사, 간판 장인, 시장 요리사, 특송원, 기업 조사관, 의회 의원 등 각 구역의 역할을 사용하며 기존 NPC 대화·충돌·피격 시스템을 따른다.

노바의 포장과 콘크리트는 실제 표면 크기에 맞춘 재질과 패널 이음새를 사용한다. 창문은 세대마다 불이 켜진 비율·색온도·블라인드를 달리한다. 주변의 조명은 기존 낮밤 시스템을 따른다.

해저에는 모래 지형과 수면 굴절광 무늬, 해조류의 흔들림, 산호·물고기·바다거북·가오리와 수중 관측소가 있다. 서하의 수면 정지·전진·후진·측면 수영은 별도 8프레임 시트 네 장을 사용하며, 잠수할 때 자세와 호흡 기포가 변한다.

## 캠페인

기존 main24 이후 main25–main30 여섯 장이 이어진다. 노바의 기억 담보 계약, 해저 관측소의 원본, 조수 발전망의 시각 조작을 조사하고 두 도시의 대피·공동 기록 규약을 결정한다. 독립적으로 선택할 수 있는 노바 주민 의뢰 네 건도 추가했다. 총 30개 현장 목표에는 실제 이동·대화·조사·잠수·전투가 포함된다. 기존 main24 완료 저장은 다음 장을 이어받는다.

## 제작과 출처

- [탈것 효과음 출처](Audio/TRANSPORT-LICENSES.md): 공개 녹음/게임용 엔진 루프 18개. 일부는 동일 엔진 계열을 공유한다. RPM·가속 부하·차내 필터·거리 감쇠를 적용했다.
- [효과음 처리 내역](Audio/transport-sources.json): 원본 URL, 라이선스, 체크섬, 트리밍·정규화 기록. 크레딧은 빌드 StreamingAssets/ThirdParty에도 포함된다.
- [이미지 생성 기록](NeonHarbor/art-generation.json): 내장 이미지 생성 도구로 제작한 NPC 여섯 시트와 서하 수영 네 시트. 원본 PNG를 프로젝트에 보관하고 Unity 임포터에서 프레임·중심점·배경 알파를 처리한다.
- 전차 포탑·포신과 헬기 로터·꼬리로터의 편집 가능한 Blender 원본은 `Documentation/Mobility/Models`에 있다.

상용 대작과 동일한 제작 규모·아트 완성도를 달성했다는 의미는 아니다. 기존 프로젝트의 제작 방식 안에서 공간 밀도와 실제 사용 기능을 확장한 버전이다.

## 필수 검증

[최종 Windows Release 빌드](NeonHarbor/build-result.json) 성공(오류 0, 기존 경고 43). [실제 Windows 실행 필수 확인 15개](NeonHarbor/essential-results.json)가 통과했다. 차량 11종의 엔진·1인칭, 실제 독립 포탑·포격 명중, 헬기 미사일 명중·탄약 차감, 맵 경계를 넘는 보트, 수영·잠수와 알파·육지 복귀, 30개 캠페인 현장 목표, 정기선의 실제 해협 횡단을 확인했다. 마지막 계기판·수중 표현 보정 후에는 [관련 확인 2개](NeonHarbor/presentation-results.json)만 다시 통과했다. 전체 캠페인 회귀나 장시간 성능 검사는 반복하지 않았다.
