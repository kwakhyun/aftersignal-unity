# AFTERSIGNAL — 필수 BGM 6곡

사용자가 Suno로 생성해 제공한 WAV 6곡을 적용했다. 다운로드 원본과 프로젝트 WAV는 SHA-256이 동일하며, 소스 음원을 잘라내거나 재인코딩하지 않았다. 파일별 출처·길이·음량·루프 구간은 `music-sources.json`에 있다. 음악은 게임에 포함되어 오프라인 재생된다.

| 파일 | 적용 구역 |
|---|---|
| 01_서하의집.wav | 서하의 집, 병원, 선착장, 시내 아파트·병원·식당·카페 |
| 02_애프터라이트.wav | 마을, 시내 도보·운전, 학교, 본부, 나머지 정상 운영 시설, 컨덕터 처치 후 |
| 08_중앙역.wav | 캠페인 중앙역, 빗속의 거리, 봉쇄된 상가, 물 아래의 도시, 옛 수로 |
| 09_밤의객실.wav | 객실, 보스 접근 전 열차 지붕, 화물 구역, 중계탑, 옥상, 용광로, 왕관, 외벽 침투 |
| 11_과부하지휘자.wav | 컨덕터 교전 시작부터 처치까지. 활성 경계 밖으로 후퇴해도 유지 |
| 16_유리잔향.wav | 연구동, 수직 기록동, 천문대, 기원 서버 |

도시 시설은 40개 출입구가 공유하는 16종 시설 테마에 따라 선택된다. 정상 운영 중앙역·물류센터는 일상곡을, 캠페인의 위험한 역·화물 구역은 긴장·전투곡을 사용한다.

## 재생과 조작

- `SignalMusic`은 씬 간 유지되는 단일 음악 재생기다. 같은 곡을 쓰는 구역에서는 곡의 현재 위치를 유지한다.
- 다른 곡은 비동기로 로드한 다음 1.8초 동안 겹쳐 전환한다. 빠르게 연속 이동할 때는 진행 중인 전환을 마친 뒤 마지막 목적지의 곡을 선택한다.
- 두 AudioSource로 곡의 끝과 처음을 2초간 겹쳐 반복한다. 100ms RMS가 -40dBFS를 넘는 구간으로 시작·끝 무음을 제외했다. 이는 무음과 갑작스러운 절단을 줄이는 크로스페이드이며, 박자·화성까지 맞춘 수동 루프 편집은 아니다.
- 곡별 측정 음량을 재생 게인으로 -18 LUFS 기준에 맞춘 뒤 전체 음량과 BGM 설정을 적용한다. 기본 BGM 설정은 55%다. 원본 피크와 다이내믹은 보존한다.
- 대화·도시 생활 메뉴에서는 음악을 원래 재생 음량의 45%로 부드럽게 낮춘다. 메뉴 종료 시 복귀한다.
- 일시정지·사망 시 두 음악 트랙의 재생 위치와 전환 진행도 멈춘다. 재개하면 이어서 재생한다.
- **ESC → 배경음악** 클릭으로 **꺼짐 → 30% → 55% → 80% → 100%**를 순환한다. 설정은 저장되며 효과음 음량과 별개다. 기존 **소리 끄기**는 음악도 함께 끈다.
- Unity 임포트는 스테레오, Vorbis 품질 80%, Streaming, 사전 전체 로드 비활성화다. 원본 WAV를 모두 PCM으로 메모리에 풀어두지 않는다. 기존 환경음·전투 효과음은 그대로 유지한다.

## 소스와 유지보수

- 원본: 사용자가 제공한 `Downloads` 폴더의 여섯 WAV. 사용자가 Suno에서 생성했다고 설명했으며 생성 날짜·플랜·라이선스 증명은 별도로 제공되지 않았다.
- 소스: `Assets/AfterSignal/Resources/Audio/Music/`.
- 수집·측정: `Tools/Import-Music.py`. 기존 로컬 ffmpeg와 NumPy가 있는 Python으로 실행한다. 다른 내용의 기존 WAV는 덮어쓰지 않는다.
- 장소 선택·게인: `MusicCatalog.cs`. 루프 구간·전환·일시정지: `SignalMusic.cs`.
- 다른 음원으로 교체하는 경우 새 음원의 음량과 길이를 다시 측정하고 카탈로그 게인과 루프 경계도 갱신한다.

## 검증

검증 결과는 이번 작업의 `Artifacts/Music`에 기록한다. 전체 게임 회귀나 스피커 청취 평가와 구분한다.

- EditMode: 25개 씬, 40개 시설의 음악 배정과 보스 상태, 여섯 WAV 임포트·스트리밍·루프 범위.
- PlayMode: 실제 씬 간 공유 음악 유지·곡 전환, 보스 접근·후퇴·처치, 일시정지·재개·전체 음소거·BGM 음소거·대화 음량·루프 재시작.
- 이번 실행: EditMode 2개, PlayMode 3개 모두 통과. 6개 원본의 SHA-256 일치 확인.
- 게임 AudioListener에서 4.44초의 실제 출력을 확보했다(`game-audio.wav`). 일시정지·음소거 구간을 포함하며, 평균 -37.8 dBFS / 최대 -24.6 dBFS로 무음이 아닌 출력과 클리핑 없음을 확인했다. 이는 주관적인 스피커 청취 검수를 대신하지 않는다.
- PlayMode에서 일시정지 메뉴 캡처를 요청했지만 배치 에디터는 PNG를 생성하지 않았다. 메뉴의 시각적 검수 증거로 간주하지 않는다.
- Windows Release 갱신 성공: `Artifacts/Music/build-result.json`, 오류 0 / 경고 36. 출력은 `Builds/Windows/AFTERSIGNAL.exe`이며 이 작업에서 새로 빌드한 플레이어의 별도 네이티브 실행 검사는 하지 않았다.
