# 목격 반응 · 소방/군용 승무원 수정

주변 인물의 부상과 사망을 구분해 직업·나이·소속에 맞는 랜덤 말풍선을 표시합니다. 가까이서 볼 수 있는 NPC만 반응하며, 같은 말의 연속 반복과 짧은 시간에 몰리는 말풍선을 제한합니다. 부상 목격 직후 사망하면 사망 대사로 바뀔 수 있습니다.

소방대원의 전용 방수/이동 프레임을 일반 시민 애니메이션이 덮어쓰던 문제를 수정했습니다. 소방차와 군용 트럭·탱크·전투헬기·전투기·폭격기의 승무원은 차량 역할에 맞춰 표시하고 하차 시에도 유지합니다. 서비스 컴포넌트가 나중에 붙거나 승객 수가 바뀌어도 일반 시민으로 돌아가지 않습니다.

검증: Windows 플레이어에서 전용 옵션 -crew-witness-probe로 필수 13개 확인, 오류 0개. 탑승/재탑승/하차, 소방관 프레임 유지, 실제 피해→부상→사망 반응, 벽 뒤/원거리 제외, 대사 재사용 제한을 확인했습니다. 이 검증의 격리용 바닥은 일반 게임에 생성되지 않습니다.
