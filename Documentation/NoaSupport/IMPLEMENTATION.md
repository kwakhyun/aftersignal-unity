# 노아의 수배 해제 지원 · 대화 일러스트 확대

서하에게 수배가 발생하면 노아가 무전으로 지원하고, 약 4초의 실제 플레이 시간 뒤 수배 기록을 삭제한다. 모든 수배 단계에 적용하며 도중에 단계가 상승해도 타이머를 다시 시작하지 않는다. 일시정지·대화·타이틀·장면 전환 중에는 시간이 진행되지 않는다. 이동과 공격을 멈추는 대화창을 열지 않는다.

노아의 개입/완료 대사는 12쌍이며 직전 대사와 연속으로 같은 대사를 뽑지 않는다. 완료 대사는 5초 동안 표시된다. 외부 대화 API 호출은 추가하지 않았다. 기존 `WantedSystem.Clear`를 사용해 경찰·차량·헬기·군 수배 대응과 대기 중인 목격 신고를 함께 해제한다. 사망·체포·다른 방식의 해제 시 진행 중인 무전을 취소한다. 이미 체포되어 수감된 서하를 자동 석방하는 기능은 아니다.

대화 초상화는 원본 텍스처의 상단을 공유하는 캐시 스프라이트로 얼굴·상반신을 확대한다. 전신 하단 여백을 줄이고 일반 대화/메인 이야기에서 초상화 폭을 약 220~246에서 396 기준 픽셀로 확대했다. 전투 무전과 시네마틱 초상화도 같은 상반신 구도를 사용한다. 대사·스크롤·입력칸·선택지·계속 버튼은 초상화 오른쪽으로 재배치했다. 원본 텍스처를 재생성하거나 저해상도로 바꾸지 않는다.

노아의 수배 무전과 캠페인 무전이 겹칠 때는 수배 지원을 먼저 표시한다. 일반 대화/일시정지 화면에서는 수배 무전을 숨긴다.

실행 대상: `Builds/NoaSupport/AFTERSIGNAL.exe`. `PLAY.cmd`가 최신 빌드 경로를 읽는다.

필수 검증은 `-noa-support-probe` 네이티브 실행으로 진행한다. 수배 발생, 5단계 상승, 약 4초 해제, 일시정지, 신고 정리, 대사 중복 회피, 외부 취소와 실제 대화 UI 캡처를 확인한다. 플레이어 진행 저장과 AI API 호출은 억제한다. 결과와 캡처는 이 폴더에 보존하며 전체 캠페인 검증은 반복하지 않는다.
