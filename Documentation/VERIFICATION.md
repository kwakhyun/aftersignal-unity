# Unity Edition 1.0.0 — verification

검증일: 2026-09-07 (KST). Unity **6000.4.0f1**, URP **17.4.0**, Windows x64 / Direct3D 11, NVIDIA GeForce RTX 4060 Ti. 이전 브라우저 버전의 테스트 결과와 구분된 Unity 프로젝트 자체의 결과입니다.

## 검증 범위

EditMode에서는 네 씬의 빌드 등록, URP 설정, 96개 주인공 프레임·48개 적 프레임·5개 NPC 이미지의 임포트, WASD/마우스 입력 바인딩, 승차·해치의 선행 조건, 일반 적 1~3타 처치 수치를 확인했습니다.

PlayMode에서는 실제 Input System 가상 키보드/마우스 이벤트가 게임 컨트롤러에 전달되는 것, X/Z 이동과 감속, 점프·대시·일시정지, 화면 좌표로 로프 앵커 선택 및 감기/해제, 실제 적 충돌체에 대한 권총·근접 공격, 방향성 방어, 유리 파괴와 충돌 해제, 객실 천장의 점프 차단, 축전기 두 개와 세 번의 코어 공격을 검증했습니다. 일부 전투 단위 테스트는 대상 위치를 직접 배치하는 독립 테스트 픽스처를 사용합니다.

Windows 전체 진행 검증은 `RuntimeSmoke`가 플레이어 입력 경계인 `ControlFrame`에 이동·공격·로프·상호작용을 넣는 방식입니다. 플레이어 위치 순간이동, 적 체력 강제 변경, 무적 모드, 진행 플래그 직접 해금 없이 다음 순서를 통과했습니다.

1. 노아 대화 → 전력 단말 → 경비병 6명 → 열차 도착과 승차.
2. 객실 전투 10명 → 유리 격벽 파괴 → 수동 잠금 해제 → 지붕 해치.
3. 로프로 객차 사이 두 번 이동 → 경비병 6명 → 축전기/코어 세 사이클 → 보스 처치와 기억 코어 회수.
4. 마을 도착 → 캠페인 완료 저장 → 노아 에필로그 대화.

총 처치 **23명(보스 포함)**, 로프 연결 **8회**, 코어 직격 **3회**를 기록했습니다. 자동 플레이의 구역별 게임 시간 합은 약 59초입니다. 이는 사람의 플레이 시간이나 성능 벤치마크가 아닙니다. 검증 모드의 시작/대화 종료에는 게임의 공개 메뉴 함수를 호출하며, 자동 플레이 종료 시 자신이 시작할 때의 저장 값을 복원합니다.

배치 실행에서는 창의 백버퍼 캡처가 검게 나오므로, 스크린샷은 `UniversalRenderPipeline.SingleCameraRequest`로 **실제 게임 카메라·3D 씬·HUD**를 렌더 텍스처에 렌더링했습니다. 그림을 새로 생성하거나 합성한 모형 화면이 아닙니다. 최종 검토에서 한국어 가변 글꼴의 기본 굵기 100 문제를 고정 굵기 500 글꼴로 해결했고, 이름과 대화 버튼의 잘림을 수정했습니다.

## 알려진 범위와 경고

- 빌드에는 포함된 Unity Core 패키지의 에디터 테스트용 `PrivateCtorAStripper`에 관한 경고 7개가 남습니다. 빌드는 성공했으며 런타임 오류는 발생하지 않았습니다.
- 이 배포물은 Windows 개발 빌드와 Unity 소스입니다. macOS, Linux, 모바일, 게임패드, 모든 GPU 및 모든 화면 비율은 검증하지 않았습니다.
- 그래픽은 실제 3D 메시와 URP 조명, 재사용한 자체 도트 아트로 구성한 독립 MVP입니다. 전체 17맵 이식이나 상용 게임 수준의 에셋 제작을 완료했다는 의미는 아닙니다.
- 천장은 충돌하지만 승차/사다리는 씬 전환, 에스컬레이터는 걸어서 이동하는 경사 충돌체입니다. 열차 주행은 열차 좌표계와 이동하는 3D 도시 배경으로 표현합니다.

## 재현

프로젝트를 닫고 `Tools/Test-Project.ps1`를 실행하면 Unity 테스트 결과가 `Artifacts/`에 기록됩니다. `Tools/Build-Windows.ps1`로 빌드 후 실행 파일에 `-batchmode -aftersignal-smoke -screen-width 1600 -screen-height 900`을 전달하면 전체 캠페인 검증 및 화면 기록이 `Artifacts/Runtime/`에 생성됩니다. 일반 실행에서는 자동 검증이 활성화되지 않습니다.
