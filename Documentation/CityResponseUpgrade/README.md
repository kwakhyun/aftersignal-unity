# 도시 대응·첫 캠페인 개선

2026-09-09. 기존 스프라이트 품질 및 집 리스폰 변경을 유지한 상태에서 추가한 작업이다.

## 플레이 변경

- 첫 메인 임무 `main01`: 진입 반경 34m, 첫 공격 전 준비 16초, 웨이브당 2명, 적 체력 48, 소총 피해 3, 사격 대기 1.65초와 조준 예고 0.9초. 첫 임무 완료 전 무작위 몬스터·갱단·테러 사건은 시작하지 않는다. 집 주변 야간 갱단 생성도 이 보호를 따른다.
- 시야에 들어온 근거리 적 머리 위에 빨간 ▼와 소속 표시. 시민은 표시하지 않고, 벽 뒤 적도 표시하지 않는다. 수배 중 추격하는 경찰·군인은 적으로 표시하되 몬스터 재난 대응 중에는 제외한다.
- 메인 대화 및 작전 무전에 발화자의 상반신 초상화를 표시한다. 20명의 신규 애니메이션풍 초상화와 기존 서하 초상화를 연결했다. 이름을 알 수 없는 비인간 음성에는 다른 인물의 초상화를 대신 표시하지 않는다.
- 일반 사건 알림은 현장 180m 안, 직접 위험인 광역 소각 예고는 100m 안에서만 표시한다. 본인이 얻은 보상과 직접 요청한 행동 결과는 유지한다.
- 구급차는 전체 활성 출동 5대가 상한이며 중상자를 우선 배정한다. 남은 환자는 대기하고 병원 복귀 차량의 슬롯이 비면 다시 배정한다. 부상자는 걸을 수 있고 중상자만 움직이지 못한다. 환자 이송 중 들것에 실제 환자 스프라이트가 수평으로 눕는다.
- 일반 갱단은 인원별로 소총·로켓·투척 폭탄을 사용하며 시민도 표적으로 삼는다. 부상으로 체력이 낮아진 대원은 빈 민간 차량을 찾아 도주하고 순찰차가 추격한다. 쉬운 첫 임무 회수대에는 중화기를 적용하지 않는다.
- 폭발과 심한 차량 손상이 화재로 이어진다. 근처 인명 피해와 시민 대피를 처리하며 소방차 최대 5대가 소방서에서 출동한다. 차량마다 대원 2명, 연결된 호스와 지붕 방수포로 화재 열량을 줄인다. 진압 후 소방서로 복귀한다. 활성 화재는 24개, 원거리 화재의 시각·피해 갱신은 거리 제한을 둔다. 화재는 게임플레이 용도의 한정된 지점 모델이며 유체 시뮬레이션은 아니다.
- 전용 펌프 소방차 모델과 남녀 소방대원 4방향/호스 자세 16프레임을 추가했다. 소방서 근무자와 소방차 탑승자도 소방관 이미지를 사용한다.
- 군 시설에 일반 가족 방문객이 생성되지 않게 하고 시설 제목에 따른 군인 직업·복장 판정을 보완했다. 루멘 방위기지 전투기 4대·전투헬기 4대는 유지한다. 별도 공군기지는 전투기 3대·헬기 2대, 개방 정비고 3동, 관제탑, 작전실, 유도로, 연료·정비 설비를 갖춘다. 해군기지에는 관제·작전실, 정비창, 보급품, 긴 부두 2개, 크레인, 정박 함정 2척을 배치했다. 두 기지에는 각 16명의 해군·공군 근무자를 배치한다.

## 소스와 이미지

초상화 원본과 소방대원 원본은 `SourceArt`, 생성 프롬프트와 참조는 `PROMPTS.md`에 있다. 게임 리소스는 `Resources/Art/StoryCast`와 `Resources/Art/ResponseCrew`이며 각각 전용 임포터로 슬라이스한다. 기존 음악과 OpenAI 대화 설정은 이 작업에서 수정하지 않았다.

필수 검증은 `CityResponseUpgradeProbe`의 네이티브 실행 결과와 캡처로 기록한다. 전체 캠페인 완주나 장시간 부하 테스트는 이번 검증 범위에 포함하지 않는다.

결과: 기능 확인 23항목 통과(`functional-result.json`), 최종 표시·리소스 확인 10항목 통과(`presentation-result.json`), 실행 오류 0. 최종 Windows 빌드는 성공했으며 오류 0, 기존 obsolete API/렌더 파이프라인 경고 등을 포함한 경고 85개, 용량 2,109,815,342바이트다. `PLAY.cmd`는 `Builds/CityResponseUpgrade/AFTERSIGNAL.exe`를 실행한다. 대화 UI 캡처는 네이티브 플레이어의 실제 UI Canvas를 진단 카메라에 렌더한 것으로, 배경은 기능 확인용 격리 공간이다.
