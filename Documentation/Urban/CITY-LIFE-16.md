# 도시 생활 확장 1.6

`PLAY.cmd`로 Windows 플레이어와 로컬 NPC 대화 서버를 함께 실행합니다. Unity 에디터에서는 기존 씬을 그대로 열면 됩니다. 새 기능은 `GameDirector`가 초기화하며 기존 StageId와 캠페인 저장 인덱스를 유지합니다.

## 조작과 이동

- **WASD + Shift**: 입력 방향으로 대시합니다. W/S 앞뒤와 대각선도 같은 대시 속도를 사용합니다.
- **마우스 오른쪽 버튼 + W**: 구조물 앵커로 이동하고 로프를 감습니다. 시내 로프 사거리는 36m이며, 기존 캠페인 구간의 20m 설정은 유지합니다. 외벽 앵커에 가까워지면 연결된 발판에 올라섭니다. 버튼을 놓았다 다시 누르면 다음 앵커를 선택합니다.
- **Space / 오른쪽 버튼 놓기**: 로프에서 도약 / 관성 이동.
- **옥상에서 V** 또는 전망대에서 **E**: 도시 전망. 방향키로 회전·높이를 조절하고 V로 돌아옵니다.
- **E**: 시민 대화, 건물 출입, 시설 이용, 침대·옷장 상호작용. 대화창에서는 말을 입력하고 Enter 또는 말하기 버튼을 누릅니다. Esc로 닫습니다.

건물과 계단이 카메라와 서하 사이에 들어오면 해당 구조물의 렌더러만 서서히 투명해집니다. 물리 충돌체는 그대로 유지합니다. 승강기·에스컬레이터는 캐릭터의 접지 상태도 함께 갱신합니다.

40개 시설 옥상과 40개 도심 고층 옥상에 외벽 발판·앵커·지붕 충돌체·전망대를 연결했습니다. 가로등·신호 기둥도 로프 대상으로 사용합니다. 도심의 가까운 외벽은 사진 형태의 상점 무늬를 제거하고 창문, 창턱, 세로 보강재를 3D 메시로 구성했습니다. 내부의 상업 간판과 외벽 사진, 열차와 함께 움직이지 않던 장식 간판을 제거했습니다.

## 재화와 시설

시작 재화는 1,500 C입니다. 캠페인 적 제압, 시설 업무, 승인한 히든 의뢰로 재화를 얻습니다. 잔액·예금·의상·시간·의뢰·수배 상태는 `AFTERSIGNAL.Unity.Life.*`에 저장됩니다.

| 시설 | 서비스 |
| --- | --- |
| 식당 | 정식 90 C, 특선 140 C / 체력·에너지 회복 |
| 카페 | 커피 35 C, 샌드위치 세트 60 C |
| 병원 | 응급 처치 60 C, 완전 회복 180 C |
| 마트 | 도시락 45 C, 에너지 음료 35 C |
| 옷가게·백화점 | 코트 구매 650/850 C, 보유 의상 착용 |
| 호텔 | 도시 지도 33번 애프터뷰 호텔 / 8시간 숙박 240 C |
| 아파트 | 게스트룸 6시간 휴식 120 C |
| 은행 | 500 C 단위 예금·인출 |
| 경찰서 | 벌금 납부, 하루 한 번 분실물 업무 |
| 소방서·학교·물류센터·본부 | 시설에 맞는 유급 업무 |
| 주유소 | 실제 주유기 옆에서 1 L당 6 C |
| 주유소·주차장 접수 | 저장된 소유 차량 정비 150 C |

개인 방 옷장에는 기본 의상 두 종류가 있으며 구입한 코트를 추가로 착용할 수 있습니다. 스프라이트의 피부와 무기는 유지하면서 의복 색을 바꾸고, 모든 무기·이동 모션에 적용합니다. 시민은 직업·성격·체형·의복 색과 가방·모자 조합을 사용합니다. 공용 시설에는 직원과 이용객을 포함해 최소 6명의 대화 가능한 인물이 있습니다.

침대에서는 6시간, 8시간 또는 다음 아침까지 취침할 수 있습니다. 실제 시간 약 30분이 게임의 하루에 해당합니다. 낮·해질녘·밤의 하늘, 태양·달빛, 안개와 주변광이 바뀌며 높은 옥상에서는 먼 도시가 더 잘 보입니다.

## 수배

시민을 무기나 운전 중인 차량으로 공격하거나 차량을 탈취하면 수배가 발생합니다. 1~5단계에 따라 경찰 2/4/6/9/12명이 출동합니다. 일반 경찰은 권총과 샷건, 특수대응팀은 소총을 사용합니다. 시내에서는 경찰차가 도로를 따라 접근하고 4단계부터 탐조등과 기관총을 갖춘 헬기가 지원합니다. 발사는 예고와 회복 구간이 있으며 벽 뒤까지 피해가 전달되지 않도록 시야를 검사합니다.

경찰에게 보이지 않은 상태를 26~58초 유지하거나 출동 병력을 모두 제압하면 해제됩니다. 실내로 이동해도 수배를 유지하고 경찰이 출입구로 진입합니다. 수배 중에는 취침과 유급 업무를 이용할 수 없습니다. 기존 캠페인 경비병과 경찰 병력은 별도로 집계하므로 경찰 때문에 캠페인 출구 조건이 바뀌지 않습니다.

## OpenAI 대화

실제 API 모델 ID는 [`gpt-5.6-luna`](https://developers.openai.com/api/docs/models/gpt-5.6-luna)입니다. Python 표준 라이브러리로 구현한 `Tools/NpcGateway.py`가 OpenAI Responses API를 호출합니다. 키는 Unity 에셋·실행 파일·PlayerPrefs에 포함하지 않습니다. 서버는 기본적으로 `127.0.0.1:8766`에서만 수신하며 기존 `OPENAI_API_KEY` 환경변수 또는 승인 후 저장한 프로젝트 `.env.local`을 읽습니다. 원격 대화 서버를 사용할 경우 `AFTERSIGNAL_NPC_URL`에 HTTPS 주소를 설정합니다.

**사용자의 로컬 저장 승인 후 현재 PC의 `.env.local`에 키를 저장하고 실제 연결을 확인했습니다.** 바리스타가 소방서 배달 의뢰와 보상 180 C를 생성했고, 의사는 병원 상황에 맞는 대화를 응답했습니다. `allowQuest=false` 요청에서는 의뢰가 생성되지 않았습니다. 키는 Git에 포함하지 않으며 다른 PC에서는 별도로 설정해야 합니다. `PLAY.cmd`가 키를 읽는 로컬 대화 서버를 함께 실행합니다. 연결에 실패하면 게임은 이를 표시하며, 고정 대사를 AI 응답처럼 표시하지 않습니다.

고정 메인·주민 퀘스트의 대사는 기존 작가 대사를 유지합니다. 그 외 시민 대화는 직업, 성격, 시설, 시간, 수배 상태와 최근 대화를 전달해 생성합니다. 의뢰는 방문·배달·옥상 관찰 세 종류, 실제 시설 0~39, 보상 120~350 C로 제한하며 플레이어가 수락해야 시작됩니다. 목적지에서 E 또는 시설 접수를 통해 완료하고 한 번만 보상을 받습니다. AI는 재화·저장 데이터·고정 퀘스트를 직접 수정하지 못합니다.

## 빌드와 최소 검증

새 씬을 통째로 생성하지 않고 기존 씬을 수정하는 메뉴는 `AFTERSIGNAL > City life > Upgrade existing scenes and build release`입니다. 구형 전체 생성 메뉴를 실행했다면 이 업그레이드를 다시 적용합니다. 소스 변경만 빌드할 때는 기존 `Tools/Build-Windows.ps1 -Release`를 사용합니다.

`-life-smoke -quality-output <경로>`는 명시적으로 선택한 경우에만 짧은 기능 통합 검사를 실행합니다. 기존 저장 항목을 검사 후 복원합니다. 전체 캠페인 재검증, 장시간 성능 측정, 출시 수준의 미술·조작감 검수는 이번 작업의 검증 범위에 포함하지 않습니다.

최종 정리 후 Windows 빌드 오류 0, 필수 동작 17개 통과입니다. 결과는 `Artifacts/Maintenance/Smoke/life-smoke.json`, 빌드 로그는 `Artifacts/Maintenance/build.log`입니다. 이후 실제 OpenAI 요청 2회로 대화·히든 의뢰 생성을 확인했습니다. 키 연결을 위해 게임 실행 파일이나 BGM을 변경하지 않았으며, 실제 게임 화면에서 의뢰 수락부터 완료까지의 재검사는 반복하지 않았습니다.
