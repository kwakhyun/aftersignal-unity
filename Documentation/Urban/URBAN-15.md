# AFTERSIGNAL 1.5 — 도시와 차량

새 게임은 기존 서하의 6층 방에서 시작합니다. 마을 동쪽의 **도시대로**에서 E를 누르면 애프터라이트 시내로 이동합니다. 기존 캠페인과 0–22 저장 인덱스는 유지하며, 시내/시설 내부는 23/24에 추가했습니다.

## 적용된 범위

- 약 790 × 660m의 이동 구역, 6개 남북 도로와 5개 동서 도로, 30개 교차로.
- 40개 기존 시설 출입구와 16종 내부 구성. 추가 고층 건물은 외형으로 구성하며, 기존 실내와 퀘스트 출입구를 유지했습니다.
- 블록 뒤편에 고층 40동, 사방 외곽에 두 겹의 빌딩군. 전면 출입구·주차장·골목·보도를 남겨 두었습니다.
- 직접 제작한 한국어 간판 PNG 16종, 입면 패널 8종, 표면 이미지 6종. 실제 도로 좌표에 맞춘 횡단보도·차선·방향 화살표 PNG.
- 승용차·택시·버스·트럭. 버스는 긴 객실·출입문·3축, 트럭은 운전석·골판 적재함, 택시는 지붕등·체크 띠로 구분합니다.
- 근접 도보 카메라, 탑승 중 차량 뒤에서 전방을 바라보는 추적 카메라. 벽이 카메라를 가리면 거리를 줄입니다.
- 도로 경로·정지선·신호·보행자 경로가 같은 좌표를 사용합니다. 차량은 우측 차선과 우회전 경로를 따릅니다.
- 메인 의뢰의 현재 목적지, 거리, 목표 표식을 자동 표시합니다. 시내에서는 실제 도로를 따르는 경로를 월드와 지도에 표시합니다. 전체 지도의 시설 선택 안내도 유지합니다.

## 조작

| 상태 | 조작 |
|---|---|
| 도보 | WASD 이동, E 차량 탑승·대화·출입, M 시내 지도 |
| 운전 | W 가속 / S 제동 후 후진, A·D 조향, Space 제동 |
| 하차 | 정차 후 E. 주유기 옆에서는 F |
| 주유 | 주유기 8m 이내에서 정차 후 E. 출발하거나 E를 누르면 중단 |
| 전투 | 기존 LMB 공격, RMB 로프, 휠·1–3 무기, R 장전, Q 기술 유지 |

연료는 실제 이동 거리에 따라 감소합니다. 승용차·택시는 27m/s, 버스 21m/s, 트럭 23m/s까지 가속합니다. 이 수치는 게임의 조작값이며 현실 차량 성능을 재현한 값은 아닙니다.

## 신호와 충돌

교차로는 66초 주기를 공유합니다. 동서 녹색 0–11초, 황색 11–13초, 남북 녹색 20–31초, 황색 31–33초, 보행 42–64초입니다. 사이의 전방향 적색 구간은 교차로를 비우는 시간입니다. 보행자는 남은 시간이 횡단에 충분할 때만 진입하고, 진입한 보행자는 끝까지 건넙니다. 일반 시민은 보도와 횡단보도 경로를 이용하며 고정 퀘스트 NPC는 시민 풀과 분리했습니다.

차량은 전면의 정지선과 선행 차량을 확인합니다. 체력은 100이며 충돌 속도에 따라 손상됩니다. 차체 색과 자세 변화, 심한 손상의 연기, 체력 0에서 한 번의 폭발로 상태를 구분합니다. 파손 차량은 재탑승할 수 없습니다. 운전 중 파손되면 플레이어 제어를 복구하고 차 밖으로 탈출합니다.

## 제작과 재현

Unity 6000.4.0f1 / URP 17.4.0 / Windows x64 Release / D3D11. 엔진·파이프라인을 변경하지 않았습니다.

- Unity 메뉴 **AFTERSIGNAL → Urban → Build city and release**: 생성 대상 시내·실내·마을 및 간판을 적용하고 릴리스 빌드.
- **Tools/Test-CityUpgrade.ps1**: 네이티브 신호 관찰과 차량·손상 검증. `-Video`는 실제 렌더 화면과 오디오를 기록합니다.
- **Tools/Test-Urban.ps1**: 탑승·탈취·시민 충돌·주유·16종 실내 왕복.
- **Tools/Test-Project.ps1**: Unity 테스트.
- **Tools/Test-ReleaseRoutes.ps1**: 기존 열차·확장 챕터·거주지·외벽 작전 회귀 검증.
- `-urban-manual`은 실제 장치 입력을 관찰하는 선택적 QA 모드입니다. 입력을 대신 생성하지 않습니다.

생성 도구는 지정된 생성 씬을 다시 작성하므로 수동 편집 씬은 먼저 복사하세요. 정상 게임 실행은 씬을 재생성하지 않습니다. 새 차량 저장 키는 이전 저장에 없을 때 승용차·체력 100으로 처리합니다.

## 출처와 한계

간판·입면·표면 이미지는 이 프로젝트용으로 새로 생성하고 확인한 아트입니다. 출처 원본은 Sources 폴더에, 가공 절차는 Build-UrbanArt.py에 있습니다. 차량 메시와 도로 마킹은 프로젝트의 생성 도구로 제작했습니다. 차량 오디오는 Build-UrbanAudio.py의 원본 합성 WAV이며 외부 게임 음원을 사용하지 않았습니다.

이 도시는 구획형 액션 게임에 운전을 결합한 구현입니다. 시설 40곳의 내부는 16종 구성을 재사용하며, 새 외곽 고층 건물의 모든 층을 모델링하지 않았습니다. 차량은 아케이드 방식의 충돌·조향을 사용하고 차체 변형은 상태 표현입니다. 경찰 추격, 도시 경제, 현실 차량 변형 시뮬레이션은 포함하지 않습니다. 레퍼런스 상용 게임과 같은 아트 품질을 달성했다고 주장하지 않습니다.

실행 결과, 비교 화면과 성능 수치는 **VERIFICATION.md / verification.json / review.html**에 별도로 기록합니다.
