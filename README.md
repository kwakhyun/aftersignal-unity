# AFTERSIGNAL · Night Line — Unity Edition

독립적인 **Unity 6.4 (6000.4.0f1) + URP 17.4.0** 프로젝트입니다. 기존 브라우저 게임은 변경하지 않습니다. Unity 에디터, Windows 네이티브 플레이어에서 실행하며 Node.js나 브라우저 서버에 의존하지 않습니다.

**새 작업은 [HANDOFF.md](HANDOFF.md)부터 읽으세요.** 적용된 기능, 실제 검증 결과, 아직 남은 시야·직접 조작·성능 과제를 구분했습니다. GitHub 소스에는 실행 파일과 대용량 QA 녹화가 포함되지 않으며, 로컬 빌드는 `Tools/Build-Windows.ps1 -Release`로 만듭니다.

**1.5 도시·차량 확장**: 790×660m 시내, 40개 시설 출입구와 16종 내부, 블록 고층 건물·사방 원경, 승용차·택시·버스·트럭, 실제 신호·횡단보도, 운전·주유·손상·폭발·차량 탈취를 적용했습니다. 도보는 근접 시점, 운전은 차량 뒤 추적 시점입니다. 메인 퀘스트 경로는 자동 표시됩니다. [도시와 조작 안내](Documentation/Urban/URBAN-15.md), [실행 검증](Documentation/Urban/VERIFICATION.md)을 확인하세요.

## 실행

- GitHub에서 복제했다면 먼저 Unity **6000.4.0f1**을 설치하고 `SETUP.cmd`를 실행하세요. 정확한 버전의 패키지를 설치된 에디터와 Unity 공식 배포 서버에서 복원합니다. 이 저장소는 **Unity 전용**이며 웹 버전 소스와 실행 파일은 포함하지 않습니다.
- 게임 실행: `PLAY.cmd` 또는 `Builds/Windows/AFTERSIGNAL.exe`.
- 편집: Unity Hub에서 이 폴더를 **Add project from disk**로 추가한 뒤 `Assets/AfterSignal/Scenes/19_SeoResidence.unity`를 열고 Play를 누르세요. `OPEN_UNITY.cmd`도 사용할 수 있습니다. 시내를 바로 확인하려면 `24_OpenCity.unity`를 엽니다.
- 권장 에디터: **6000.4.0f1**. 다른 Unity 6 버전으로 자동 다운그레이드하지 마세요. 에디터에서 패키지와 씬을 가져오는 첫 실행에는 시간이 필요합니다.
- 씬, 충돌체, 조명, NPC, 앵커, 적 위치를 Hierarchy/Inspector에서 직접 수정할 수 있습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| W / A / S / D | 3D 공간에서 앞 / 왼쪽 / 뒤 / 오른쪽 이동 |
| 마우스 왼쪽 버튼 | 현재 무기로 공격. 누르고 있으면 연속 공격 |
| 마우스 오른쪽 버튼 유지 | 커서 부근의 청록색 앵커에 로프 연결 |
| 로프 중 W / S | 로프 감기 / 풀기 |
| 오른쪽 버튼 놓기 | 로프 해제, 관성을 유지하며 이동 |
| Space | 점프. 로프 중에는 도약하며 해제 |
| Left Shift | 무적 시간이 있는 대시 |
| Left Ctrl | 바라보는 쪽 방어 |
| Q | 카타나 월광참 / 중검 지각 붕괴 / 권총 전술 연사 |
| E | 대화, 단말 조작, 차량 탑승·정차 후 하차, 출입·주유 |
| 운전 중 WASD / Space | 가속·후진·조향 / 제동 |
| F / M | 차량 하차 / 시내 지도 |
| 1 / 2 / 3 또는 마우스 휠 | 카타나 / 중검 / 권총 전환. 공격 중에는 회복 후 전환 |
| R | 권총 12발 탄창 장전 (1.15초). 빈 탄창은 자동 장전 |
| Shift + 왼쪽 클릭 | 무기별 대시 공격 |
| Esc | 일시정지, 대화 닫기 |

이동 중에는 이동 방향으로, 공격·방어 중에는 마우스 조준 방향으로 바라봅니다. 앞뒤 이동에는 무기별 전용 스프라이트를 사용합니다. 앵커는 화면상 조준 범위, 최대 20m 거리, 지형에 가려지지 않은 시야를 모두 만족해야 선택됩니다. 조준 가능한 앵커에는 다이아몬드 표시가 나타납니다. 사격 시작점은 실제 도트 스프라이트의 총구 좌표에 맞춰 계산합니다.

## 독립 캠페인

새 게임은 서하의 6층 0607호에서 시작합니다. 침대·옷장·컴퓨터·냉장고를 조사하고 현관문을 연 뒤 승강기 또는 실제 5개 층간 계단으로 1층에 내려갑니다. 마을에서는 W/S로 앞뒤 거리를 오가며 학교·병원·본부 내부에 들어갈 수 있습니다. 북동쪽 본부의 중앙역 단말에서 첫 임무를 시작합니다. 기존 저장을 이어 하면 원래 진행 구역을 유지합니다.

1. **중앙역** — 노아와 대화, 상층 전력 단말 복구, 에스컬레이터 경사로를 따라 승강장 진입, 경비병 6명 제압, 진입하는 열차의 문이 열리면 E로 승차.
2. **달리는 객실** — 객실 3개에 배치된 경비병 10명 제압, 공격으로 유리 격벽 파괴, 수동 잠금 단말 작동, 객실 끝 사다리에서 E로 지붕 진입.
3. **도시 위의 열차** — 로프와 점프로 객차 사이를 건너 경비병 6명 제압. 양쪽 CAP 01 / CAP 02 앵커에 로프를 걸어 컨덕터의 코어 노출. 가까이서 카타나 또는 중검으로 공격하면 체력의 1/3에 해당하는 코어 피해. 3번의 과부하 사이클 후 동쪽 기억 코어 회수.
4. **애프터라이트** — 234m의 주요 거리와 앞뒤 도로·횡단로, 상층 산책로, 작업실 승강기, 옥상 정원, 학교·병원·본부. 기존 노아·민·윤·다미·해진과 새 시설 주민·보행자를 만납니다.

보스의 붉은 충격파는 사전 예고 후 발동합니다. 점프·로프 또는 초록색 SAFE 지점으로 피하세요. 일반 적은 무기에 따라 1~3번의 공격에 쓰러집니다. 처치 시 체력과 에너지를 일부 회복합니다.

구역 이동 시 진행 상황을 자동 저장합니다. 사망하면 현재 구역 입구에서 다시 시작합니다. 저장 키는 `AFTERSIGNAL.Unity.*`이며 기존 브라우저 저장과 별개입니다.

마을에서 노아에게 의뢰를 받고 광장 아래 노선 단말로 **챕터 2: 청계의 기억(7구역) → 챕터 3: 왕관의 균열(3구역) → 챕터 4: 기억의 기원(3구역)**을 진행합니다. 각 챕터의 마지막 중계기를 복구하면 마을로 돌아옵니다. 선착장 보급품과 옥상 방송 수신은 별도의 주민 의뢰입니다.

첫 열차 임무 클리어 후 본부의 **외벽 침투 · 스물네 번째 창**이 열립니다. 4개 로프 앵커를 타고 올라가 24층 유리창을 깨고 기록실에 진입합니다. 경비병 14명, 기록 회수, 전력 복구를 마치면 마을로 돌아옵니다. 상승할 때 RMB를 유지하며 W로 감고, 발이 발판보다 높아지면 Space와 D로 건너가세요.

## 개발 구조

- `Assets/AfterSignal/Runtime/` — 캐릭터, 로프, 전투, 적, 진행, UI, 카메라, 열차 배경 이동, 사운드.
- `Assets/AfterSignal/Scenes/` — 편집 가능한 25개 씬. 기존 0~22 저장 인덱스를 보존하고 시내·공용 시설 씬을 추가했습니다.
- `Assets/AfterSignal/Prefabs/` — 서하, 적, 보스 프리팹.
- `Assets/AfterSignal/Resources/GameTuning.asset` — 이동, 로프, 공격 수치.
- `Assets/AfterSignal/Resources/Controls.inputactions` — Unity Input System 입력 에셋.
- `Assets/AfterSignal/Shaders/PixelActor.shader` — URP 3D 렌더러용 도트 캐릭터 셰이더.
- `Assets/AfterSignal/Editor/ProjectBuilder.cs`, `WorldBuilder.cs` — 씬과 에셋 생성 도구.
- `Assets/AfterSignal/Tests/` — EditMode / PlayMode 검증.
- `Packages/` — 버전 고정 manifest, lock, sources 목록. 이 PC의 UPM 폴더 이름 변경 오류를 피하기 위해 로컬에서는 embedded 패키지를 사용합니다. 대용량 SDK 사본은 Git에서 제외하며 `SETUP.cmd`가 동일 버전을 복원합니다. 게임 에셋은 모두 저장소에 포함됩니다.

`AFTERSIGNAL > Build authored scenes and settings`는 생성된 25개 씬을 다시 작성합니다. 수동으로 편집한 씬을 보존하려면 먼저 다른 이름으로 저장하세요. 일반 플레이나 프로젝트를 여는 동작은 씬을 재생성하지 않습니다.

## 빌드와 검증

- `Tools/Build-Windows.ps1` — 설치된 에디터로 Windows 개발 빌드 생성.
- `Tools/Build-Windows.ps1 -Release` — 릴리스 플레이어 생성. 현재 PC에서 검증한 실행 파일은 릴리스 빌드입니다. GitHub 소스와 Windows 배포 파일은 구분합니다.
- `Tools/Test-Project.ps1` — Unity Test Framework의 EditMode / PlayMode 테스트.
- 개발 빌드에 `-aftersignal-smoke`를 전달하면 실제 이동·공격·상호작용 로직을 구동하는 캠페인 QA가 실행되고 스크린샷 및 JSON 기록을 남깁니다. 이 모드는 일반 실행에서 활성화되지 않습니다.
- 실제 검증 결과와 범위는 `Documentation/VERIFICATION.md`를 확인하세요.
- 이전 1.2 결과는 `Documentation/Expansion/VERIFICATION.md`와 `verification.json`입니다. 1.1 당시 결과는 `Documentation/Quality/QUALITY.md` 및 `verification.json`입니다. 이전 `VERIFICATION.md`의 측정은 1.0 당시 기록입니다.

최신 검증은 Documentation/Urban/VERIFICATION.md에 있습니다. 마을 동쪽 도시대로에서 E로 새 시내에 진입합니다. M에서 주유소와 시설을 확인하세요.

## 범위

기존 **지하철역 → 객실 → 지붕 보스 → 마을** 뒤에 세 개의 후속 챕터를 연결한 독립 Unity 게임입니다. 브라우저 버전의 지역 테마를 참고했으며, 18개 Unity 씬의 지형과 의뢰를 새로 구성했습니다. 웹 게임의 모든 규칙을 그대로 이식한 버전은 아닙니다.

배경은 Unity의 실제 3D 메시, URP 재질, 그림자, 조명, 안개와 후처리로 구성했습니다. 도트 캐릭터는 기존 프로젝트의 자체 제작 프레임을 재사용했습니다. 캐릭터를 완전한 3D 모델이나 새 스켈레탈 애니메이션으로 교체한 것은 아닙니다. 컨덕터는 기존 보스 아트를 재사용합니다.

열차의 플레이 공간은 고정된 열차 내부 좌표계를 사용하며 주변 도시 메시가 여러 속도로 이동합니다. 승차와 사다리 진입은 페이드와 씬 전환입니다. 추가 구역의 에스컬레이터는 연속 경사 충돌체 위의 플레이어를 위층으로 운반하고, 승강기는 E로 조작하여 실제 발판과 탑승자를 함께 이동시킵니다. 고속 주행 열차 전체를 월드 물리로 운행하거나 별도의 사다리 오르기 애니메이션을 구현한 버전은 아닙니다.

프로젝트에 사용한 이미지·음원·폰트·패키지의 출처와 사용 조건은 `Documentation/ASSETS.md`에 기록했습니다.
